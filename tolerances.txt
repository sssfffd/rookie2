# IO 별 허용 오차. groups.txt · config.txt 와 같은 방식입니다 — 손으로 고치는 파일입니다.
#
# 한 줄에 IO 하나, 설정 창의 [IO 별 허용 오차] 두 칸 순서 그대로:
#
#     IO이름 = 퍼센트, 절대값
#
# 빈 칸은 기본값입니다 (설정 창에서 칸을 비워 둔 것과 같음).
#
#   TT-01  = 20          <- 퍼센트만 20 %
#   VALVE  = , 0         <- 절대값만 0
#   PT-01  = 5, 0.1      <- 둘 다
#
# 퍼센트는 0 ~ 100 (끝에 % 를 붙여도 됩니다), 절대값은 0 이상.
# 숫자가 아니거나 범위 밖이면 그 칸은 빈 칸 (기본값) 으로 봅니다.
# IO 이름은 느슨하게 맞춥니다 — 띄어쓰기나 _ - . 가 달라도 같은 IO.
# 같은 IO 가 또 나오면 뒤의 줄이 이깁니다.
#
# ───────────────────────────────────────────────────────────────
# 누가 이기나
#
#   이 파일이 규칙을 하나라도 정하면 이 파일이 주인입니다.
#   켤 때 이 규칙으로 맞추고, 설정 창에서 고친 것은 다시 켜면 되돌아갑니다
#   (그래서 설정 창에 그렇다고 적힙니다).
#
#   위처럼 전부 주석이면 아무것도 하지 않습니다. 그때는 설정 창에서 걸고
#   LogScope.settings.json 에 저장하는, 지금까지의 방식입니다.
#
# 설정 창의 [tolerances.txt 글 복사] 를 누르면 지금 건 규칙이 이 꼴로
# 클립보드에 담깁니다. 여기에 붙여넣고 빌드하면 됩니다.
# out\tolerances.txt 를 바로 고쳐도 됩니다 — 그때는 빌드할 필요가 없습니다.
