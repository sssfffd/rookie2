# 그룹 설정. config.txt 와 같은 방식입니다 — 손으로 고치는 파일입니다.
#
# 한 줄에 그룹 하나:
#
#     그룹이름 = IO1, IO2, IO3
#
# IO 이름은 로그에 적힌 그대로 쓰세요. 쉼표 · 세미콜론 · 탭으로 가릅니다
# (엑셀에서 한 줄을 복사해 붙여넣어도 됩니다).
#
# 같은 이름이 또 나오면 앞의 그룹에 더합니다. 긴 목록을 여러 줄에 나눠
# 적을 때 씁니다.
#
# 이름만 적고 IO 를 비워 두면 빈 그룹이 만들어집니다. 화면에서 IO 를
# 끌어다 넣으려고 자리만 잡아 두는 쓰임입니다.
#
#   가열부 = TEMP_1, TEMP_2, HEATER_ON
#   압력   = PRS_MAIN, PRS_SUB
#   예비   =
#
# ───────────────────────────────────────────────────────────────
# 누가 이기나
#
#   이 파일이 그룹을 하나라도 정하면 이 파일이 주인입니다.
#   켤 때 이 그룹으로 맞추고, 화면에서 고친 것은 다시 켜면 되돌아갑니다
#   (그래서 그룹 칸에 그렇다고 적힙니다).
#
#   위처럼 전부 주석이면 아무것도 하지 않습니다. 그때는 그룹을 화면에서
#   묶고 LogScope.settings.json 에 저장하는, 지금까지의 방식입니다.
#   설명만 적힌 이 빈 틀이 그때까지 묶어 둔 그룹을 지워 버리면 안 되니까요.
#
# 어디에 두나
#
#   저장소 뿌리(여기)에 두면 build.bat 이 out 폴더로 넣어 줍니다.
#   out\groups.txt 가 이미 있으면 덮지 않습니다 — 거기서 고쳐 놓았을 수
#   있어서입니다. out\groups.txt 를 바로 고쳐도 되고, 그때는 빌드할
#   필요가 없습니다 (프로그램만 다시 켜면 됩니다).
#
#   화면에서 묶어 둔 것을 이 꼴로 뽑으려면 그래프 화면 왼쪽 아래의
#   [groups.txt 글 복사] 를 누르고 여기에 붙여넣으세요.
