# LogScope 설정. 이 파일 하나만 고치면 됩니다.
# 고치고 프로그램을 다시 켜면 바뀝니다. 지우면 기본값으로 돕니다.
#
#   name      창 제목과 왼쪽 위에 적히는 이름.
#             실행 파일 이름(out\<이름>.exe)도 이걸 따라갑니다 — 그건
#             build.bat 이 복사할 때 붙이므로 다시 빌드해야 바뀝니다.
#   fullname  이름과 판 번호 사이에 작게 적히는 긴 이름. 길어도 됩니다.
#   analysis1 분석 화면의 이름. "이름 | 한 줄 설명" 으로 적습니다.
#   analysis2 세로줄(|) 뒤는 메인 화면 칸에 적히는 설명입니다 (없어도 됩니다).
#   analysis3
#
# 이 파일은 build.bat 이 out 폴더에 같이 넣어 줍니다. out\config.txt 를
# 바로 고쳐도 됩니다 (그때는 다시 빌드할 필요가 없습니다).
#
# 메모장으로 고쳐도 됩니다. UTF-8 로 저장하든 ANSI 로 저장하든 읽습니다.

name = LogScope

# 이름과 판 번호 사이에 작게 적히는 긴 이름. 비워 두면 안 적힙니다.
fullname = Log 비교 · 분석 도구

analysis1 = 로그 비교 | 이전 Log 파일과 이후 Log 파일을 비교합니다. 대시보드 · 그래프 · 히트맵.
analysis2 = DB 분석 | 두 DB 의 표·열·값 차이를 보고 맞추는 SQL 을 만듭니다.
analysis3 = 분석 3 | 아직 정해지지 않았습니다.

# ---- 분석 2 (DB) ----
#
# 견줄 DB 두 벌의 자리. 폴더면 그 안의 .sql / .csv 를 읽고, 파일 하나면
# 그 파일을 읽습니다.
#
# db.before = D:\db\2026-03-14
# db.after  = D:\db\2026-03-21
#
# 선택 — 돌고 있는 서버에서 덤프를 받아 읽습니다.
#
#   db.mysqldump    mysqldump 실행 파일의 자리. 이걸 적어 두면 아래 두 줄은
#                   인수만 적으면 됩니다.
#   db.dump.before  덤프 인수. (db.mysqldump 를 비워 두면 이 줄이 명령 줄
#                   전체가 됩니다 — 실행 파일까지 포함해서.)
#
#   * mysqldump 는 서버에 접속해서 뽑습니다. 멈춘 .frm/.ibd 만으로는 못 뽑습니다.
#   * 암호를 인수에 적으면 작업 관리자에 보입니다. --login-path 나
#     --defaults-extra-file 을 쓰세요.
#   * 적어 둔 실행 파일을 자식 프로세스로 띄웁니다. 남이 바꿔 쓸 수 있는
#     폴더를 가리키지 마세요.
#
# db.mysqldump   = C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe
# db.dump.before = --login-path=old --databases mydb
# db.dump.after  = --login-path=new --databases mydb
#
# 선택 — 멈춘 .ibd 에서 표와 열 "이름만" 꺼냅니다 (값은 못 꺼냅니다).
# MySQL 8.0 의 .ibd 에만 통합니다. 폴더에 표.frm 과 표.ibd 가 짝으로 있으면
# 5.x 라서 .ibd 안에 꺼낼 것이 없습니다 — 그때는 아무것도 적지 않아도 됩니다.
# .frm 은 이 프로그램이 직접 읽습니다 (모양만). 값은 mysqldump 로 받으세요.
# db.ibd2sdi = C:\Program Files\MySQL\MySQL Server 8.0\bin\ibd2sdi.exe
