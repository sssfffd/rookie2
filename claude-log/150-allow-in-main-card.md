# 150 — 오차 허용을 메인 칸에서 (따로 창 없이) · 오차 목록 메뉴 빼고 메뉴 줄 되돌리기 (1.59)

> 아 그리고 오차 허용을 이렇게 창 따로 만들어서 하면 안되지 ㅋㅋ
> 이거 히트맵/그래프에서 선택해서 하거나
> 메인화면에서 요약칸에 그룹누르면 io들이 뜸 그러면 그 io또 누르면 구간별 오차 발생들이 뜸
> 그러면 그거 허용으로 선택할 수 있게 해야됨
>
> 이거때문에 2줄됬겠네
> 오차목록 메뉴바에서 지우면서 이전처럼 메뉴바 돌려줘

## 바뀐 것
| 무엇 | 1.58 | 1.59 |
|---|---|---|
| 메뉴 줄 | [오차 목록] · 줄인 단추 글 · 좁은 여백 | **1.57 그대로** ([대시보드][그래프][히트맵] [이전 로그 열기][이후 로그 열기][비교 다시 하기]) |
| 분석 1 [오차 목록] 화면 (F4) · 허용 창 | 있음 | **뺌** (JudgeView · JudgeVm · AllowPrompt · JudgeTexts) |
| 메인 분석 1 칸 그룹 줄 누르기 | 그래프로 감 | **IO 들이 펼쳐짐** — 그래프는 줄 오른쪽 [그래프] |
| IO 줄 누르기 | — | **구간별 오차**가 펼쳐짐 |
| 오차 줄 | — | [그래프] (그 구간) · **[이번만 허용] · [앞으로도 허용]** · 허용됐으면 [허용 풀기] |
| 그룹 "N / M 달라짐" | 예전 비교 (같은 시각 · 한 점) | **판정 기준** (허용 안 된 값 오차가 있는 IO) · 아래 글 = 가장 긴 오차 |
| 공정 단계 · 한쪽에만 있는 IO 오차 | 오차 목록 화면 | 칸 맨 위 줄 둘 (펼치면 오차 줄) |
| 앞으로도 허용 지우기 | 오차 목록 화면 아래 | 설정 창 **[허용한 오차]** 탭 |

```
 분석 1  FAIL   차이 발생 4 개
 ▾ ● 묶지 않은 IO                              4 / 6 달라짐   [그래프]
       가장 긴 오차: BIG · 20.1초
     ▾ ● SPIKE  오차 1 · 가장 긴 0.1초                          [그래프]
         WARNING  12:00:40.1 · 0.1초 · 최대 250   [그래프][이번만 허용][앞으로도 허용]
     ▸ ● BIG    오차 1 · 가장 긴 20.1초                         [그래프]
       ● FLAT   오차 없음                                       [그래프]
```

펼치면 그룹 칸 높이 상한 230 → 520. History 를 펼쳐 보는 중에는 펼치기 · 허용이 안 됨 (그때 요약).

## 아직 안 한 것
- 히트맵 · 그래프에서 골라 허용 ("하거나" 라서 메인 칸 먼저) — 원하면 다음에
- 대시보드 "차이 발생 IO 개수" · 목록은 예전 비교 그대로

## 확인
- Linux: 테스트 1054 통과 (펼치기 · 허용 · 공정 단계 줄 · 설정 탭), 실제 csc 7.3 오류 · 경고 0, XAML 형식 · 처리기 · 이름 겹침 · 소스 검사 통과
- **Windows 에서 못 봄**: 펼친 모양 · 단추 줄 바꿈 · 칸 높이, 설정 [허용한 오차] 탭, 메뉴 줄 (1.57 과 같음 — 창이 좁으면 두 줄)
