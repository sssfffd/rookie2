# 211 — 2.07 "종합 분석 결과" → "종합 Report"

## 요청 (요청 238)

> 그리고 종합 분석 결과 대신
> 종합 Report로 이름 바꿔주셈

## 한 것

| 자리 | 전 | 후 |
|---|---|---|
| 메인 화면 칸 제목 (`MainTexts.Label`) | 종합 분석 결과 | **종합 Report** |
| 결과가 없을 때 안내 (`LlmEmpty`) | … 여기에 종합 분석 결과가 나옵니다 | … 여기에 종합 Report 가 나옵니다 |
| [LLM 분석 실행] 마우스 글 | … LLM 종합 분석을 돌립니다 | 체크한 분석의 결과로 LLM 이 종합 Report 를 만듭니다 |
| 설정 창 LLM 서버 안내 · [연결 확인] 마우스 글 | … 종합 분석 결과를 쓸 수 있습니다 | … 종합 Report 를 쓸 수 있습니다 |
| README · 발표 자료 두 개 (아키텍처 1 · 3 장, 오버뷰 2 장 제목) | 종합 분석 결과 | 종합 Report |

- 사용자 폴더 `LlmExport/` 의 글 (LLM 에게 주는 요청문 "'종합 분석 결과' 를 한국어로 써 주세요") 은 건드리지 않음 — 사용자 폴더.
  바꾸려면 `LlmExport/LlmPrompt.cs` 의 Request 한 줄.
- [LLM 분석 실행] 단추 이름은 그대로.
