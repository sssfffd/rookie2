# 66 — 실패한 것만 맨 밑에 모아 찍기 (0.85)

## 주신 말

> 그리고 build.bat 돌렸을 때 맨 밑에 실패한 부분들만 모아서 띄워줘

시험이 **669 개**입니다. FAIL 줄이 OK 줄 사이에 묻히고, 테스트는 빌드
중간에 지나가서 그 뒤의 복사·완료 글에 또 밀려 올라갑니다. 화면을
한참 거슬러 올라가야 보이던 자리였습니다.

## 고친 것

### 1) 테스트 프로그램이 실패만 모아 맨 밑에 다시 찍습니다

```
통과 665 / 실패 4

실패한 것만 모으면 (4 개)
  ------------------------------------------------------------
  [DB — 줄 색과 세 숫자] FAIL  값이 달라진 줄은 빨강 (a · b 두 열)  — 3
  [DB — 줄 색과 세 숫자] FAIL  v1 이 달라진 줄은 노랑  — 0
  [DB — 줄 색과 세 숫자] FAIL  v1 은 곁값 열
  [DB — 줄 색과 세 숫자] FAIL  대소문자 안 가림
```

**어느 묶음에서 났는지**를 앞에 붙입니다 (`[DB — 줄 색과 세 숫자]`).
전에는 FAIL 줄만 보면 어느 영역인지 알 수 없어서 그걸 찾으려고 또
거슬러 올라가야 했습니다.

이걸 위해 묶음 머리글을 찍는 62 군데를 `Say()` 한 함수로 바꿨습니다 —
찍으면서 지금 묶음 이름을 기억합니다. 두 군데(찍기 · 기억하기)로
나누면 새 묶음을 더할 때 한쪽을 빠뜨립니다.

### 2) build.bat 이 빌드가 **다 끝난 뒤** 한 번 더 찍습니다

테스트 출력은 빌드 중간입니다. 그래서 `completed` 글 아래에 다시
찍습니다.

```
 ============================================================
 완료.
 실행 파일 : ...\out\LogScope.exe
 ============================================================

 [알림] 테스트가 실패한 채로 만들어졌습니다.
        값을 다루는 쪽이 틀렸을 수 있습니다.

  ------------------------------------------------------------
  [DB — 줄 색과 세 숫자] FAIL  값이 달라진 줄은 빨강 ...
  ------------------------------------------------------------
        같은 목록이 ...\test.fail.log 에도 있습니다.
```

테스트 프로그램이 `test.fail.log` 에 **FAIL 줄만** 적고, build.bat 이
그걸 `type` 으로 찍습니다.

### 3) 두 가지를 조심했습니다

**인코딩.** 파일을 윈도우에서는 **ANSI(CP949)** 로 적습니다 — UTF-8 로
적어 두면 `type` 이 CP949 콘솔에 찍을 때 한글이 깨집니다. 윈도우 밖에서는
반대로 `Encoding.Default` 가 ASCII 로 잡혀 물음표가 되므로 UTF-8 로
적습니다. 콘솔 인코딩을 정하는 쪽과 **같은 판단**(`Windows()`)을 씁니다.

**지난 실패가 남는 것.** 전부 통과하면 그 파일을 **지웁니다.** 안 지우면
다음 빌드에서 지난번 실패가 "지금 실패" 로 보입니다. build.bat 도 돌리기
전에 한 번 지웁니다 (테스트가 아예 안 돌아간 경우를 위해).

## 확인한 것

- 일부러 깨뜨려 네 개를 실패시키고 **모아 찍히는 것**을 봤습니다
- 성공했을 때 **파일이 지워지는 것**을 봤습니다
- 파일에 적힌 한글이 안 깨지는 것을 봤습니다
- `test.fail.log` 를 `.gitignore` 에 넣었습니다
- `통과 669 / 실패 0`, 검사기 넷 지적 없음
- `build.bat` 은 CP949 · CRLF 그대로입니다

## Windows 에서 확인 못 한 것

`cmd.exe` 를 여기서 돌릴 수 없습니다. 다음만 봐 주세요.

- 테스트가 **전부 통과**하면 맨 밑에 아무 글도 안 나와야 합니다
- 실패가 있으면 `완료` 아래에 목록이 한 번 더 나와야 하고, **한글이
  안 깨져야** 합니다 (깨지면 인코딩 쪽이니 바로 고칩니다)
