# 42 — 도구 줄 두 줄, [그릴 로그] 는 왼쪽 IO 칸으로

> 요청: "저거 선보기 들어간거 너무짜친다 일단 위에 3줄인데 2줄 넘지않게(메뉴)
> 그리고 그래프 표시를 선보기 말고 다른표현으로하고 색넣지마 해당기능은
> 오른쪽 아래 그래프화면이나 왼쪽 선택메뉴쪽에 있는게 좋겠네"

## 무엇이 잘못됐나

0.48 에서 [선 보기] 를 **도구 줄에** 넣었습니다. 셋이 잘못됐습니다.

1. 도구 줄이 **세 줄**이 됐습니다. 그래프가 들어갈 자리를 먹습니다.
2. 단추 글자에 **색을 넣었습니다.** 파랑/주황 글자 두 개가 회색 도구 줄
   가운데 박혀서, 다른 단추들과 따로 노는 모양이 됐습니다.
3. 자리가 틀렸습니다. "무엇을 그릴까" 는 **IO 를 고르는 일과 같은 종류**인데
   확대·눈금 단추들 사이에 끼어 있었습니다.

## 어떻게 고쳤나

### 왼쪽 IO 칸으로 옮겼습니다

```
IO 목록   184 개
[검색                      ] [검색 지우기]
[전체 타입 ▾] [모든 IO ▾]
[전체 선택] [전체 해제]
그릴 로그   ☑ 이전   ☑ 이후        ← 여기
```

- 이름은 **[그릴 로그]**. "선 보기" 는 무엇을 보는 건지("선" 이 뭔지)
  설명하지 않습니다. 그릴 로그를 고르는 것이니 그렇게 적었습니다.
- **색을 뺐습니다.** 그냥 체크 상자입니다. 어느 쪽이 어느 색인지는 그래프
  오른쪽 위 범례가 이미 보여 줍니다 — 같은 말을 두 군데서 할 이유가 없습니다.
- 전체 선택/해제 바로 아래입니다. 위에서 아래로 "무엇을 고를까 → 무엇을
  그릴까" 로 읽힙니다.

이 블록의 `DataContext` 는 IO 목록(`List`)이라, 그래프 뷰모델의 값은
`UserControl` 을 거쳐 찾습니다.

```xml
IsChecked="{Binding DataContext.ShowBefore,
            RelativeSource={RelativeSource AncestorType=UserControl}, Mode=TwoWay}"
```

### 도구 줄을 두 줄로

```
전: 보기 | 세로 눈금 | Time Scale | Value Scale | 선 보기 | 비교 | 맞추기    (세 줄)
후: 보기 | 세로 눈금 | Time Scale | Value Scale | 비교 | 맞추기            (두 줄)
```

둘을 했습니다.

- **[선 보기] 묶음을 뺐습니다** (위로 옮김).
- `차이 (이후−이전)` → **`차이`**. 뜻은 풍선 도움말에 그대로 있습니다
  (`두 로그의 차이를 선 하나로 그립니다. 같으면 0, 이후가 1 크면 +1 …`).
  단추 하나에서 70 픽셀쯤 줍니다.

높이 상한도 132 → **88** 로 내렸습니다. 줄 하나가 42 라 두 줄이면 84,
글꼴 차이만큼 몇 px 만 얹은 값입니다. 창이 아주 좁아 더 접히면 **그 안에서
굴러갑니다** — 어느 경우에도 도구 줄이 그래프 자리를 먹지 않습니다.

**"(여러 IO 선택시)" 는 그대로 뒀습니다.** 폭을 줄이려면 그 괄호를 떼는 게
제일 쉽지만, 그건 0.25 에서 직접 요청하신 글자입니다. 제가 보기 좋으라고
요청하신 것을 지울 수는 없습니다.

## 자체 테스트

테스트 399 통과(그대로). 자리만 옮긴 것이라 Core 에 붙일 것이 없습니다.
XAML 파싱·`x:Name`·처리기 서명·테마 열쇠 검사는 다 돌았습니다.

### 아직 확인 못 한 것

**두 줄이 되는지는 창 폭에 달려 있습니다.** 여섯 묶음의 폭 합이 대략
1400 픽셀이라, 그래프 쪽 폭이 700 이상이면 두 줄입니다 (1360 창에서 왼쪽
칸을 320 쯤 두면 1040 → 두 줄). **그보다 좁게 쓰시면 세 줄째가 생기고 그때는
굴러갑니다.** 쓰시는 창 크기에서 두 줄이 되는지 봐 주시고, 아니면 [Value
Scale] 의 [구간 맞춤]·[계속 맞춤] 을 팝업으로 접겠습니다 — 가로축·시간
맞추기를 접어 둔 것과 같은 방식입니다.

체크 상자 두 개가 왼쪽 칸 폭에 들어가는지도 봐 주세요 (칸이 좁으면 `이후` 가
아래로 내려갑니다 — `WrapPanel` 이라 잘리지는 않습니다).
