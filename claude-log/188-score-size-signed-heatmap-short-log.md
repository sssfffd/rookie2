# 188 — 1.93 점수에 오차 크기 · 히트맵 부호 / 100 % 넘음 · 짧게 끊긴 로그

## 요청 (요청 215)

> 점수에 각 오차 발생에서 차이가 얼마나 발생했냐도 반영되어야 함. 히트맵이 100 % 까지만 나오던데 100 % 이상도, 기준은 이전 값,
> − + 도 붙여 줘야 됨. 공정 실패가 나면 로그 하나는 시간이 매우 짧을 수도 있음 — 오차랑 히트맵 같은 곳에도 반영.

## 1) 점수 — 오차 크기

오차 칸 (이전 로그 시간 100 칸) 마다 **무게 = 1 + 벗어난 % / score.size** (기본 50, 최대 3). 벗어난 % 는 판정 오차의
`MaxExcessPercent` (그 오차 구간에서 가장 크게 벗어난 정도, 범위 끝 값 기준). 한 칸에 오차가 여럿이면 큰 무게.

```
IO 크기 반영 오차율 = min(100, Σ 칸 무게)      (시간 오차율 = 칸 수 — 화면에 같이)
점수 = 100 × (1 − 차이 IO / 전체 IO) × (1 − 크기 반영 평균 오차율 / 100) × 로그 길이 계수
```

| 같은 10 칸 오차 | 시간 오차율 | 크기 반영 |
|---|---|---|
| 1 % 벗어남 | 10 % | 10.2 % |
| 50 % 벗어남 | 10 % | 20 % |
| 300 % 벗어남 | 10 % | 30 % |

메인 칸: "평균 오차율 10 % (크기 반영 30 %) · 로그 길이 70 % 다름". `config.txt` 에 `score.size = 50` 추가. LLM 글도.

## 2) 히트맵 — 부호 · 100 % 넘음 · 이전 값 기준

100 % 까지만 보였던 까닭: **이전 값이 0** 이면 % 를 낼 수 없어 100 % 로 적었음 (디지털 IO 등). 그리고 차이를 절댓값으로만 담음.

| 이전 → 이후 | % 보기 | 값 보기 |
|---|---|---|
| 2 → 8.8 | +340% | +6.8 |
| 10 → 4 | −60% | −6 |
| 0 → 5 | Δ+5 | +5 |
| 상태 이름 다름 | ≠ | ≠ |

칸에 `PeakDelta` (이후 − 이전) · `PeakBefore` 를 더 담음. 색 · 줄 차례는 그대로 부호 없는 `PeakPercent` (사용자 `LlmExport` 가 씀 —
그대로). 마우스 글: "+340% (이전 값 기준) (이전 2 → 이후 8.8, +6.8)". 칸이 커져 (44 바이트) 칸 수 상한을 240 만 칸으로
(IO 200 개면 12000 칸).

## 3) 짧게 끊긴 로그 (공정 실패)

전에는 **겹치는 시간만** 봐서 이후 로그가 중간에 끊겨도 끊긴 뒤는 아무 데도 안 잡혔고, 히트맵은 끝난 뒤를 **마지막 값으로 견줬음**.

| 어디 | 이제 |
|---|---|
| 판정 | 새 종류 `JudgeKind.LogLength` (끝에 더함 — 값 7): "이후 로그가 일찍 끝남 — 70초 (이전 로그 길이의 70 %)" · 늦게 시작 · 일찍 시작 · 더 김. 시간 여유 (단계 길이 2 %, 시각이면 최대 5 초) 보다 클 때만. 20 % 넘으면 CRITICAL, 판정 전체도. 이번만 허용 가능 |
| 메인 칸 | "로그 길이" 줄 (눌러서 보고 허용) · 점수에 덮은 비율을 곱함 |
| 히트맵 | 판정에 로그 길이가 있으면 겹치지 않는 시간도 칸으로 — `이후 없음` · `이전 없음` (진한 색), 그런 IO 는 줄에 넣음. 알림 줄. 끝난 뒤를 마지막 값으로 견주던 것은 고침 |
| LLM 글 | 종류 "로그 길이", 로그 길이 계수 |

## 확인

- 시험 1110 통과 (새: 끊긴 로그 → 오차 · 70 % · CRITICAL · 30 점 · 0.5 초는 여유 안 · 이번만 허용 → PASS 100,
  무게 곡선 · 같은 시간 다른 크기, 히트맵 +340 · −60 · Δ+5 · 이후 없음 칸 · 알림, 단계 시험의 "로그 길이" 줄).
- check 스크립트 · 실제 csc 빌드 (사용자 `LlmExport` 포함) 통과.
- **Windows 에서 못 본 것**: 히트맵 칸 글자 (+ · − · Δ · ≠ 가 좁은 칸에 들어가는지), "이후 없음" 색, 메인 칸 줄 길이.
- 짚어 둘 것: 기록 시작 · 끝 시각이 원래 몇 초씩 다른 로그는 이제 "로그 길이" 로 잡힐 수 있습니다 (시각 로그 여유 최대 5 초) —
  그때는 이번만 허용, 또는 알려 주시면 여유를 따로 둡니다.
