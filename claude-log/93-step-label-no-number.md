# 93 — 단계 이름 앞의 "1." 빼기

> 그리고 분석 1에서 단계나누면 1.x이렇게 뜨는데
> 1. 이거 안뜨게 해줘

## 바뀐 것

```
전 (1.12)                          후 (1.13)
1. 준비  2. 가열  3. 유지  4. 가열   준비  가열  유지  가열 (2)
1. 1     2. 2     3. 3             1     2     3        ← 단계 IO 값이 숫자일 때
```

- 앞의 순번(`1.`)을 뺐습니다. 단계 이름 그대로입니다.
- **같은 이름이 두 번째부터는 `(2)` 를 붙입니다.** 안 붙이면 단계 목록에
  `가열` 이 둘 떠서 어느 쪽인지 고를 수 없습니다. 처음 나온 것은 그대로 `가열`.
- 이름이 빈 단계(직접 파싱해 넣으면서 이름을 안 준 경우)는 순번만 적습니다 —
  빈 칸 머리는 무엇인지 알 수 없습니다.

이름을 만드는 곳이 `StepTable.Label` 한 곳이라 아래가 같이 바뀝니다.

| 자리 | |
|---|---|
| 그래프 단계 목록 | `가열 (2)` |
| 나눠 보기 칸 머리 | `가열` |
| 커서 정보 | `09:12:42  (가열 시작 +12.300)` |
| 히트맵 [가로를 단계로] 칸 머리 · 마우스 설명 | `가열` |

이전 로그에 없고 이후 로그에만 있는 단계는 전처럼 `(이후만) 가열` 입니다.
