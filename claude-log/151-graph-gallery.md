# 151 — 그래프 갤러리 보기 (가로 3 칸) (1.60)

> 아 그리고 그래프 보기 선택할 때
> 세로로 일렬로 뜨는 거 말고 한
> 가로 3개로 해서
> 갤러리 형식 느낌으로 칸별로 io그래프 보는 기능도 만들어주셈

## 만든 것
그래프 도구 줄 [보기] 에 **`갤러리`** — `Lane` · `Overlay` · `갤러리` 셋 중 하나.

```
 ┌ PRES_MAIN ──────┐ ┌ TEMP_1 ─────────┐ ┌ V1 ─────────────┐
 │ 60 ┤   ╱‾‾‾‾╲    │ │ 80 ┤ ‾‾‾╲___    │ │ 1 ┤ ┌──┐  ┌─    │
 │ 40 ┤__╱      ╲__ │ │ 40 ┤        ╲_  │ │ 0 ┤─┘  └──┘     │
 │ 12:00:00 12:10:00│ │ 12:00:00 …      │ │ 12:00:00 …      │
 └──────────────────┘ └─────────────────┘ └─────────────────┘
 ┌ PRES_SUB ───────┐ ┌ …
 모든 칸 같은 구간  12:00:00 ~ 12:10:00
```

- 칸마다 IO 하나 · 왼쪽에 그 IO 의 세로 눈금 · 아래에 시작 · 끝 시각
- 시간 구간은 모든 칸이 같음 — 한 칸에서 휠 · 끌기 · 오른쪽 네모 확대를 하면 모두 같이 (세로 확대 · Shift+휠은 그 칸만)
- 커서 A · B 는 모든 칸에 같은 자리
- 칸 높이 최소 170, 많으면 아래로 굴림. 단계로 나눠 보기 · 차이 눈금 · 차이 영역 표시도 칸 안에서 그대로
- 설정에 남음 ("galleryMode")

구현: 새 판을 여러 개 만들지 않고 GraphCanvas 한 장에 칸을 나눠 그림. 마우스 자리를 "그 칸 안 위치 → 판 전체 위치" 로
바꿔(Pos) 확대 · 이동 · 커서 코드를 Lane 과 같이 씀.

## 확인
- Linux: 테스트 1060 통과 (보기 셋 바꾸기 · 설정 저장), 실제 csc 7.3 오류 · 경고 0, XAML · 처리기 · 이름 겹침 · 소스 검사 통과
- **Windows 에서 못 봄**: 칸 모양 · 눈금 글자 겹침 · 마우스 확대/이동이 칸에서 맞는지 · 단계로 나눠 볼 때 칸 안 위치 (칸 사이 틈이 판 전체와 비율이 달라 경계 근처는 조금 어긋날 수 있음)
