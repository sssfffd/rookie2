# 201 — 2.02 최종 판정: 가중 종합 점수 (AHP 54 · 30 · 16) + 넉아웃

## 요청 (요청 228)

> 지금 판정중에 가장 나쁜 판정을 기준으로 삼는다고 되어있는데 이거 다른걸로 해야됨
> 분석 1의 비중이 큰 게 좋음
> 비중 적당히 맞춰주고
> 막 2대1대1로 했다는 없어보이니까 좋은 기준이나 포장 방법좀

## 새 기준 — "가중 종합 점수 + 넉아웃"

1. **가중치는 AHP (계층분석법) 쌍대비교로** — 의사결정에서 널리 쓰는 방법. 둘씩 짝지어 "어느 쪽이 몇 배 중요한가" 만 정하면
   가중치가 계산으로 나오고, 판단이 앞뒤가 맞는지 (일관성 비율 CR) 도 숫자로 확인됨.

   | 비교 | 판단 | 까닭 |
   |---|---|---|
   | 분석 1 : 분석 2 | 2 배 | 분석 1 은 설비가 실제로 어떻게 움직였나 (결과), 분석 2 는 설정이 바뀌었나 (원인 후보) |
   | 분석 1 : 분석 3 | 3 배 | 분석 3 은 보조 · 확장 분석 |
   | 분석 2 : 분석 3 | 2 배 | 설정 변화는 동작 변화를 설명하는 직접 근거 |

   → 고유벡터 **0.540 · 0.297 · 0.163 = 54 : 30 : 16**, 일관성 비율 **0.008** (0.1 아래면 일관된 판단).
2. **점수 맞추기** — 분석 1 은 공정 일치율 그대로, 분석 2 · 3 은 판정 구간의 가운데 점수 (정상 97.5 · 주의 87.5 · 이상 40,
   경계 95 · 80 일 때). 종합 점수 = 결과가 있는 분석만의 가중 평균 (없는 분석은 빼고 다시 나눔).
3. **판정** — 종합 점수를 공정 일치율과 같은 경계 (95 정상 · 80 주의) 로.
4. **넉아웃 (안전장치)** — 주 분석 (분석 1) 이 이상이면 평균과 상관없이 최종 이상. 다른 분석이 이상이면 최종은 적어도 주의.

| 예 | 예전 (가장 나쁜 것) | 이제 |
|---|---|---|
| 분석 1 96 · 분석 2 정상 · 분석 3 주의 | 주의 | 종합 95.1 → **정상** (분석 3 줄은 주의로 보임) |
| 분석 1 85 · 분석 2 이상 | 이상 | 종합 68.9 → 이상 |
| 분석 1 78 (이상) · 분석 2 · 3 정상 | 이상 | 종합 87.0 이지만 넉아웃 → **이상** |
| 분석 1 100 · 분석 2 이상 · 분석 3 정상 | 이상 | 종합 81.6 → **주의** |

- 칸: 판정 아래 "종합 점수 95.1" (넉아웃이면 까닭도), 마우스를 올리면 셈법.
- `config.txt`: `final.weights = 54, 30, 16` · `final.gate = 1` (0 이면 점수만).
- 파일: `Main/OverallVm.cs`, `Settings/AppConfig.cs`, `Main/MainView.xaml`, `config.txt`, README, 발표 자료 (1 · 3 장 · 메모).
