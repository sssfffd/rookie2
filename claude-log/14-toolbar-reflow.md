# 14 — 눈금 단추를 누르면 도구 줄이 접히던 것

> 요청: "그리고 기존값이랑 정규화 변화량 눌렀을때 메뉴 바 줄바꿈이 생기는데
> 이거 왜이래"

제가 [12번](12-tolerance-base.md)에서 넣은 안내 글 때문입니다.

---

## 1. 무엇이 문제였나

세로 눈금 모드를 고르면 옆에 한 줄이 붙게 해 뒀습니다.

```xml
<TextBlock Text="{Binding ScaleHint}"
           Visibility="{Binding ScaleHint, Converter={StaticResource TextToVisibility}}" />
```

글이 없으면 `Collapsed` — **자리까지 없어집니다.** 그런데 그 글이

```
레인 보기에서는 눈금에 적히는 숫자만 바뀝니다. 그림이 달라지는 것은 겹쳐보기입니다.
```

45 자쯤 되어서 300 px 가 넘습니다. 도구 줄은 좁아지면 저절로 줄을 바꾸는
`WrapPanel` 이라, 이만한 덩어리가 생겼다 없어졌다 하면 **그때마다 도구 줄
전체가 다시 접힙니다.**

```
기존 값  →  정규화     안내 글 300px 등장  →  뒤쪽 묶음들이 아랫줄로
정규화   →  기존 값    안내 글 사라짐      →  다시 윗줄로
```

단추를 누를 때마다 도구 줄 높이가 바뀌니, 누르려던 다음 단추가 다른 자리로
가 버립니다. 설명을 붙이려다 쓰기 더 나쁘게 만들었습니다.

---

## 2. 어떻게 고쳤나

**글을 짧게 줄이고, 자리를 고정했습니다.**

| | 예전 | 지금 |
|---|---|---|
| 도구 줄에 적는 글 | 45 자 (300 px) | 12 자 안쪽 (150 px 고정) |
| 글이 없을 때 | `Collapsed` — 자리 사라짐 | 그대로 150 px 차지 |
| 줄바꿈 | 허용 | `NoWrap` — 높이도 안 변함 |
| 긴 설명 | 없음 | 마우스를 올리면 풍선 도움말 |

```xml
<TextBlock Text="{Binding ScaleHint}"
           ToolTip="{Binding ScaleHintDetail}"
           Width="152" TextWrapping="NoWrap"
           TextTrimming="CharacterEllipsis" />
```

`Visibility` 를 아예 안 씁니다. 글이 있든 없든 **폭이 똑같아서** 도구 줄이
움직일 이유가 없습니다.

짧은 글은 이렇습니다.

```
레인 보기    →  "레인에선 눈금 숫자만 바뀜"
겹쳐보기     →  "채널마다 따로 변환됨"
기존 값      →  (빈 칸)
```

긴 설명은 그대로 살아서 풍선 도움말로 나옵니다. 라디오 단추 세 개에도
각각 풍선 도움말을 달아 뒀습니다.

---

## 3. 같은 문제가 하나 더 있었습니다

허용 오차 묶음의 안내 글도 길이가 변합니다.

```
값 범위의 0.1% 까지는 같은 것으로 봅니다
값 범위의 0.05% 까지는 같은 것으로 봅니다 (절대 0.5 과 비교해 큰 쪽)
```

숫자를 고치면 한두 글자, 절대 오차를 켜면 한 뭉치가 늘어납니다. 같은 식으로
줄이고 고정 폭(150 px)을 줬습니다.

```
"까지는 같은 값"                 (절대 오차 꺼짐)
"까지는 같은 값 + 절대 오차"     (켜짐)
```

자세한 내용 — 몇 % 인지, 절대 오차가 얼마인지, 무엇의 % 인지 — 는 풍선
도움말로 옮겼습니다.

### 도구 줄 전체를 훑었습니다

도구 줄 안에서 **길이가 변할 수 있는 글자**가 더 없는지 기계로 확인했습니다.
`{Binding}` 으로 글을 받으면서 폭이 안 잡힌 요소를 찾았고, 지금은 그래프
도구 줄과 히트맵 도구 줄 모두 0 건입니다.

왼쪽 IO 목록 위의 개수 표시(`CountText`)는 남겨 뒀습니다. 그건 폭이 정해진
왼쪽 칸 안에서만 움직이고, 개수가 바뀌면 글자가 바뀌는 게 당연한 자리입니다.

---

## 4. 배운 것

`WrapPanel` 에 든 것은 **크기가 변하면 이웃이 전부 움직입니다.** 도구 줄처럼
사람이 연달아 누르는 곳에서는 이게 꽤 거슬립니다. 앞으로 도구 줄에 뭘 넣을
때는

- 길이가 변하는 글은 **폭을 고정**하거나,
- 도구 줄 밖(아래 띠, 풍선 도움말)으로 보낸다

는 쪽으로 하겠습니다.
