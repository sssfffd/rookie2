# 79 — 단계 IO 를 바로 적용 · 로그 칸을 위아래로 · 칸 밖 휠 · 커서에 단계 경과

> 그 분석1에서 단계별로 나누는거 로그 설정에서 기입하면 바로 적용가능하게
> ㄱㄴ? 그리고 분석 1,2에 로그 파일칸 뜨는거 지금 가로로 2개 배치하니까
> 파일명이 짤려서 위아래로 세로배치하고 가로 길게 ㅇㅋ?
>
> 그리고 단계별로 나눌때 시간축 확대도 되게 바꾸고
> 단계별로 할 때 클릭해서 뜨는 정보로 각 단계 시작에서 몇초 지났는지 뜨게

## 1. 단계 IO — 설정을 닫으면 바로 들어갑니다

전에는 로그를 **읽는 자리**에서만 단계를 찾았습니다. 그래서 설정에 이름을
적어 놓고도 파일을 다시 열어야 들어갔습니다.

그게 왜 나쁜가: **이름을 한 번에 맞게 적는 일이 드뭅니다** (대소문자, 밑줄,
공백). 한 번 틀릴 때마다 10M 칸을 다시 읽는 꼴입니다.

`AppState.ReapplySteps()` 를 뒀습니다 — 이미 메모리에 있는 채널을 한 번
훑어 단계를 다시 찾습니다. 설정 창이 닫힌 뒤, **이름이 바뀌었을 때만**
돕니다. 못 찾으면 그 이유를 띄웁니다 (조용히 두면 적어 놓고도 왜 단추가
안 켜지는지 알 수 없습니다).

같이 버리는 것: 짝 목록, 고른 단계, 히트맵 그림. 단계가 통째로 달라졌으니
그 위에 세워 둔 것은 다 옛것입니다.

시험도 그 길로 걸었습니다 — 단계 없이 읽은 로그에 나중에 `StepRead.Fill`
하면 단계가 들어오고, 이름을 비우면 없어집니다.

## 2. 로그 칸을 위아래로

```
전                              후
┌ 로그 ──────────────────┐      ┌ 로그 ──────────────────┐
│ ┌이전──────┐┌이후──────┐│      │ ┌ 이전 ───────────────┐ │
│ │2026-03-1…││2026-03-1…││      │ │ 2026-03-14_가열_A.csv│ │
│ └──────────┘└──────────┘│      │ └────────────────────┘ │
└────────────────────────┘      │ ┌ 이후 ───────────────┐ │
                                │ │ 2026-03-20_가열_A.csv│ │
                                │ └────────────────────┘ │
                                └────────────────────────┘
```

나란히 놓으면 칸 하나가 카드 폭의 **절반**이라 파일 이름이 잘립니다. 날짜가
앞에 붙은 긴 이름이 보통이라 **뒤쪽(무엇을 받은 로그인지)이 먼저** 잘려
나갔습니다 — 가리는 데 제일 필요한 부분입니다.

분석 1 의 로그 칸과 분석 2 의 견줄 자리, 둘 다 바꿨습니다.

**그만큼 카드가 길어집니다.** 화면이 작으면 메인 화면에 스크롤이 생깁니다
(0.65 에 칸 높이를 390 으로 줄인 까닭이 그것이었습니다). 길어서 못 쓰겠다
싶으면 칸 안의 줄 하나(IO·표본 수)를 빼면 그만큼 돌아옵니다.

## 3. 칸 밖에서 굴려도 확대되게

칸마다 확대는 0.95 에 넣었는데, **칸 위가 아니면 아무 일도 안 했습니다.**
칸 사이의 틈이 10 px 이고 왼쪽 눈금 자리와 아래 눈금 띠도 칸이 아니라,
거기서 굴린 사람은 "확대가 안 된다" 로 읽습니다.

이제 칸 밖에서 굴리면 **모든 칸을 같이** 확대합니다 (키보드 +/- 와 같은
동작). 칸 위에서 굴리면 그 칸만 — 그대로입니다.

## 4. 커서에 "단계 시작에서 몇 초"

```
커서 A: 09:12:42  (2. 가열 시작 +12.300)     커서 B: 없음 …
```

칸으로 나눠 보면 가로가 시각이 아니라 **공정 차례**입니다. 시각만 적어 두면
그 자리가 어느 단계의 어디인지 다시 세어 봐야 합니다. 단계 시작에서 센
시간이면 **다른 단계의 같은 자리와 바로 견줄 수 있습니다.**

셈은 판(`GraphCanvas.StepInfo`)이 합니다 — 칸 경계를 들고 있는 쪽이 거기라서
입니다. 글자는 `TimeText.Elapsed` 한 곳에서 나옵니다 (날짜 로그의 경과
시간이 1970 년으로 찍히지 않게).

## 시험

`통과 823 / 실패 0` (+6). 읽어 둔 로그에 나중에 단계를 넣는 길과, 이름을
비우면 단계가 없어지는 것.

확대와 커서 글자는 WPF 입력·그리기라 시험이 닿지 않습니다 — 눈으로 봐야
합니다.
