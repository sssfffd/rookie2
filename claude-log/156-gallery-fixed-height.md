# 156 — 갤러리 칸 높이 고정 (1.65)

> 아 그리고 갤러리로 보기할때
> 3개 이하면 전체 차지 6개면 절반 이런데
> 그냥 절대값으로 해주셈
> 한 지금 4줄 생겼을때(4분의1) 정도 크기로 하면 적당할 것 같네

| | 1.60 ~ 1.64 | 1.65 |
|---|---|---|
| 칸 높이 | 판 높이 ÷ 줄 수 (최소 170) — IO 3 개 이하면 판 전체, 6 개면 절반 | **180 고정** — IO 수와 상관없이 |

180 = 보통 창(1360×860)에서 네 줄일 때 크기쯤. 줄이 화면보다 많으면 아래로 굴림. 바꾸려면 `GraphCanvas.GalleryCellH`.

## 확인
- Linux: 테스트 1074 통과, 실제 csc 7.3 오류 · 경고 0
- **Windows 에서 못 봄**: 실제 크기가 네 줄일 때와 비슷한지 (창 · 화면 배율에 따라 다름)
