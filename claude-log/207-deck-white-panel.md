# 207 — 보고 자료: 아래 표 빼고, 오른쪽은 흰 바탕 + 테두리

## 요청 (요청 234)

> 아니 이건 너무 많아 아래 꺼 지우면 될 꺼 같고
> 오른쪽 디자인만 좀 바꿔주먄 될 것 같은데
> 테두리만 치고
> 안에는 흰색으로 해줘

## 한 것

- 왼쪽 아래 표 (판정 기준 · 결과 보고서 구성) 를 지우고 화면 캡처 칸을 다시 위아래 꽉 차게.
- 오른쪽 기능 칸: 남색 바탕 → **흰 바탕 + 남색 테두리**. 제목 남색, 설명 짙은 회색, 번호는 파란 사각형 그대로, 구분선 옅은 회색.
- 기능 4 개 × 설명 3 줄은 그대로 (종합 분석 결과의 "결과 보고" 첫 줄은 표가 빠져 "종합 판정 · 핵심 변화 · 원인 후보 · 확인할 것" 으로).
