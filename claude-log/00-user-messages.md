## 요청 1 — 처음 (rookie2 에서 새로 시작)

> dummy rookie에서 개발하던거 아예 뜯어고쳐서 rookie2에서 새로 개발하려고함
>
> IO 로그를 그래프로 그려주는 Windows 프로그램을 만들려고 해. 아래가 전체 요구사항이야.
>
> ## 0. 먼저 — 언어와 구조를 정하는 것부터
> 지금은 C++ / Win32 + Direct2D / DLL+EXE 구조로 만들어져 있는데, **언어랑 구조를
> 바꾸려고** 새로 시작하는 거야.
> visual studio 2017
> C# / python(ai 활용 묘듈, 옵션 기능으로 존재, 추후 직접 구현 예정) / CMake 활용
> 제약:
> - Windows 데스크톱 프로그램. **Windows 7 / 10 / 11 셋 모두**에서 빌드되고 실행돼야 함.
> - **외부 라이브러리는 보안 때문에 자제해야 함.** 안 쓰는 게 제일 좋고, 꼭 써야 하면
>   뭘 왜 쓰는지랑 위험해 보이는 부분을 설명해줘.
> - 설치 프로그램 없이 **파일만 복사해서 실행**할 수 있어야 함.
>   런타임을 따로 깔아야 하면 그것도 미리 알려줘.
> - 내 PC에 있는 건 **Visual Studio 2017까지**. VS Code도 쓰는데 확장은 안 깔 거임.
>   확장 없이 빌드되는 진입점(build.bat 같은 것)도 만들어줘.
> - **1000만 칸(채널 200 x 표본 5만) 정도의 엑셀 로그**를 열어서 부드럽게 그려야 함.
>   이게 언어 선택에 제일 크게 걸리는 부분일 거야. 메모리도 신경 써줘.
> - 구조는 **파일 파싱/데이터 부분과 UI 부분이 나뉘어** 있으면 좋겠어.
>   (지금은 DLL + EXE 인데, 다른 방식이 더 맞으면 그렇게 해도 됨)
>
> ## 1. 입력 데이터
> - 엑셀 파일(.xlsx)과 CSV 둘 다 읽을 수 있게.
> - 로그는 시간축 한 줄 + 나머지가 각 시간별 데이터 값들. 각 줄의 첫 칸은 IO 이름.
> - **행이 IO인 배치와 열이 IO인 배치 둘 다** 지원해야 함 (우리 로그는 열이 IO명임).
>   자동 판별 + 수동 지정 둘 다 가능하게.
> - 엑셀 중간부터 log 데이터들이 존재함 (앞에 장비명/측정일시 같은 머리말이 붙음).
>   표가 시트 중간에서 시작해도 찾아내야 함.
> - IO 이름은 엑셀에 있는 실제 이름을 그대로 가져와야 함 (IO_1 같은 자동 이름 말고).
> - 파일 크기 상한은 없게 해줘. 큰 파일도 열려야 함.
> - 한 번 연 파일을 다시 열 수 있어야 함.
> - 시간축 관련 주의사항:
>   - 시간 칸이 값 바뀔 때만 적혀 있고 중간이 비어 있어도 시간축으로 인식해야 함.
>   - 같은 시각이 여러 표본에 반복되면(분 단위 표기에 초 단위 기록 등) 화면에서 한 점에
>     겹쳐 몇 분치가 안 보이게 됨. 다음 시각까지 고르게 펴서 배치해줘.
>   - 시각이 전부 같으면 샘플 번호를 시간축으로 써야 함.
>   - 0이 몇 분 동안 지속되는 구간도 빠짐없이 반영돼야 함.
>
> ## 2. 그래프
> - 가로축 = 시간, 세로축 = 값. 시간에 따른 변화를 볼 수 있게.
> - 보기 방식 두 가지:
>   - 레인: 채널마다 한 줄, 각자 세로 눈금
>   - 겹쳐보기: 하나의 세로 눈금을 여러 채널이 공유
> - 확대/축소 기능. 휠로 확대할 때 한 칸에 너무 많이 커지지 않게 점차적으로.
> - 시간축을 옮겼을 때 세로 배율이 갑자기 풀리지 않게 (기본은 전체 범위 고정,
>   "보이는 구간에 맞춤"은 버튼으로 켤 때만).
> - **값 축(세로) 확대도 돼야 함.** IO 범위가 몇천인데 1 정도 바뀌는 것도 확인하고 싶음.
>   시간만 확대되고 값은 그대로면 확인이 힘듦.
>   - Shift+휠로 값 축 확대, 커서가 가리키던 값이 제자리에 남게.
>   - 세로 눈금 모드: 원래값 / 0–1 정규화 / **변화만**(채널마다 기준값을 뺌).
>   - 레인에서도 "보이는 구간에 맞춤"이 되게.
> - 세로 눈금 숫자와 실제 그래프 높이가 항상 일치해야 함 (어긋나면 안 됨).
> - 커서 A/B, 커서 위치의 값 표시.
> - 성능: 그래프 여러 개 동시에 보면서 시간 이동할 때 버벅이지 않아야 함.
>   표본이 픽셀보다 촘촘하면 픽셀 열마다 최소/최대만 뽑아 그리는 식으로.
> - 로그 여는 시간도 가능한 한 짧게. (표를 통째로 복사/전치하지 않기 등)
>
> ## 3. IO 선택
> - 처음 시작할 때 IO들이 다 선택되어 있으면 안 됨. 아무것도 선택 안 된 상태로 시작.
> - 전체 선택 / 전체 해제 버튼.
> - Shift, Ctrl로 여러 개를 쉽게 선택. **Shift 범위는 화면에 보이는 순서를 따라야 함**
>   (그룹 순서를 바꾼 뒤에도 보이는 대로).
> - 다른 IO를 선택했을 때 이전에 선택한 IO가 꺼지면 안 됨.
>   끄는 건 같은 IO를 다시 클릭했을 때만.
> - IO 이름 검색창. 마우스를 그래프 위에서 움직여도 검색창이 깜빡이면 안 됨.
> - 타입 필터(전체/디지털/아날로그/상태).
> - **고른 IO만 보는 목록** 필터도 있어야 함. 순서는 그래프에 그려지는 차례 그대로.
> - 그래프에 그려지는 순서가 왼쪽 목록 순서를 따라가야 함.
>
> ## 4. 그룹
> - IO를 10개 단위로 묶어서 그룹화, 왼쪽에서 그룹 토글로 보였다 안 보였다.
> - **그룹 이름을 내가 변경할 수 있게.**
> - **드래그나 검색 추가로 원하는 IO를 그룹에 넣을 수 있게.**
> - **그룹 순서도 바꿀 수 있게.**
> - 그룹 설정은 한 번 하면 저장돼서 프로그램 껐다 켜도 유지돼야 함.
>   (구성원을 채널 번호가 아니라 IO 이름으로 저장해서 다른 파일을 열어도 붙게)
> - 그룹 전체 선택 체크박스, 그룹 삭제, 고른 IO를 그룹에 담기.
>   버튼은 기호(+, ×)만 쓰지 말고 무슨 기능인지 글자로 적어줘.
>
> ## 5. 두 로그 비교 (이전 / 이후)
> - 같은 양식의 로그 2개를 넣어서 각 IO의 차이를 볼 수 있게. 이전 로그 / 이후 로그.
> - 이전과 이후 그래프의 색이 확실히 구분되게.
> - 겹치는 부분 구분이 쉽도록: 차이 구간 음영, 벌려 그리기 옵션 등.
>   (점선은 쓰지 마. 직선과 빈 공간 때문에 파형 표현이 나빠짐)
> - 두 로그의 시작 시간이 다를 수 있으니 align 기능 (자동 정렬 + 수동 밀기).
> - **IO 존재 차이도 알 수 있게.** 이전에만 있는 IO / 이후에만 있는 IO를
>   각각 모아서 한 화면에서 볼 수 있게 해줘.
> - 차이량 측정 방법을 여러 개 제공해줘. 차이 총합만 쓰면 +1/-1 같은 사소한 진동이
>   반복될 때 값이 너무 크게 나옴. (최대/평균/RMS/면적/시간비율/샘플수/구간수 등)
>   허용 오차 조절도 가능하게.
> - 값이 달라진 IO만 보는 필터.
>
> ## 6. 설정 창
> - 오른쪽 위 설정 버튼을 누르면 설정 창이 나오게.
> - 설정 창에서 프로그램 버전을 확인할 수 있게.
> - **로그 세트 6개.** 한 세트 = 이전 로그 + 이후 로그 한 쌍.
>   1번부터 6번까지, 1번 선택하면 1번 비교 화면, 2번 선택하면 2번 비교 화면.
> - 로그 파일 열기를 하면 이전에 열었던 폴더가 뜨는데, 이걸 설정 창에서
>   **세트마다 각각 default로 열 폴더를 설정**할 수 있게 (이전용/이후용 따로).
> - 설정도 저장돼서 프로그램 껐다 켜도 유지.
>
> ## 7. UI 일반
> - 설명이나 숫자, 버튼들이 서로 겹치면 안 됨. 창이 좁아지면 줄바꿈되고,
>   버튼이 영역 밖으로 튀어나오지 않게.
> - 버튼이 무슨 기능인지 알 수 있어야 함 (화살표 같은 기호만 있으면 안 됨).
> - 로그 열 때 지금 읽고 있는 건지 멈춘 건지 알 수 있게 진행 표시 + 취소 버튼.
>   읽는 동안 창이 멈추면 안 됨(배경 스레드).
> - 다크/라이트 테마, 모니터별 DPI 대응.
>
> ## 8. 작업 방식
> - 나는 폰으로 프롬프트를 넣고 git은 PC에서 봄. 그러니 네 답변 내용을 git에서 볼 수
>   있게 레포에 대화 내용 저장하는 폴더를 만들고 거기에 답변도 저장해줘.
> - 파일 업데이트할 때마다 버전 0.01씩 올려줘. 버전은 한 곳에만 두고,
>   설정 창에 버전이랑 커밋 해시가 같이 보이게.
>
> 그리고 이번에는 ui가 좀 깔끔했으면 좋겠네
> 기본 바탕은 흰색에 위에 메뉴 목록들은 진한 파랑 느낌으로
>
> 그리고 바로 그래프가 나오는게 아니라 대시보드가 먼저 나왔으면 함
> 이전과 이후 log 분석 결과로 네모칸으로 각각 나눠서 IO개수(io 변수명 자체가 달라진 거는 괄호치고 몇개 발생으로) / 차이발생 IO개수/ 큰 네모 칸으로 차이가 난 IO list들 나오게
> 그리고 io list에서 io 클릭하면 그래프 창으로 넘어감(위에 메뉴에서도 이동할 수 있어야함) 그래프 창에서 클릭한 io만 자동으로 체크되면서 그래프 보여주게
> 만약에 직접 메뉴로 그래프 창 이동했을 때도 io 선택할 수 있게 이전 프로젝트 처럼 그래프 창에서 왼쪽에 i/o 목록이나 그룹 띄우고 체크할 수 있게 이전 플젝 기능도 거의 다 반영해서 다시 만들어줘(rookie2 레포에)

→ `RelayCommand` 생성자가 실제로 모호했습니다 (매개변수 목록 없는 익명 메서드가
  `Action` 과 `Action<object>` 둘 다로 변환됨). 생성자를 하나로 줄이고,
  `build.bat` 은 `build.log` 를 남기고 더블클릭이면 창을 붙들도록 고쳤습니다.
  빌드할 것은 **LogScope.App** 하나이고, 실행 파일은 `out\LogScope.exe` 입니다.
