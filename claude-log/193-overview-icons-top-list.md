## IO별 이상 · 주의 기준 (질문 답)

- **이상**: 그 IO 의 허용 안 된 오차 중 하나라도 **그 공정 단계 길이의 20 % 넘게** (`JudgeOptions.CriticalRatio` = 0.20)
  허용 오차 밖에 있었을 때, 또는 IO 가 **한쪽 로그에만 있을 때** (이후에 없음 · 이후에만 있음).
- **주의**: 차이는 있지만 위에 안 걸릴 때 (모든 단계에서 오차 시간이 단계 길이의 20 % 미만).
- 다 "허용" 처리한 IO 는 차이 IO 에서 빠짐.
- 20 % 는 코드 값 (설정 화면 · config.txt 에 없음). 오차 **크기** (몇 % 벗어났나) 는 등급에 안 들어가고 점수 · 줄 차례에만 들어감.
