# 95 — Delete 로 커서 지우기 · 그래프 아래 설명 빼기 · 맨 아래 파일 줄 빼기 · 단계 단추 둘

> 그래프에서 커서 지우기 어떻게해

→ 지우는 길이 없었음을 알려 드리고 [커서 지우기] 단추 + Delete 를 제안

> delete키로 해주고 그래프창 아래 섷명들 가 날려주셈
>
> 그리고 맨 아래 파일들 이름들 뜨는거 빼라니까?
> 그리고 단계마다 나누는 기능에서 버튼명 내가 바꾸고 싶고
> 단계별로 표시되는 숫자에도 내가 원하는 글자 덧붙이고 싶은데 어디서 수정해야돼?
> 아 그리고 단계기능 버튼들은
> 가장 왼쪽 메뉴명은 정렬로 하고
> 단계마다 이거랑 전체구간 이렇게 두개만 남기면 될 것 같아

## 1. Delete = 커서 지우기

그래프를 한 번 누른 뒤(그러면 그래프가 키를 받습니다) **Delete** 를 누르면 커서
A · B 가 둘 다 지워집니다. 커서가 없을 때는 아무 일도 안 합니다. 단추는 달지
않았습니다 (Delete 로 해 달라고 하셔서).

## 3. 창 맨 아래 파일 이름 줄 — 이번엔 다 뺐습니다

1.05 에 "분석 2 에서만 숨기고 분석 1 에는 남김" 으로 했던 게 잘못 읽은 것이었습니다.
`ShellWindow.xaml` 에서 그 줄을 통째로 지웠고, 그 글을 만들던 `ShellVm.StatusText` ·
`UpdateStatus` 도 지웠습니다.

> 그 줄에는 로그 읽기 알림(`NotesText`, 예: 못 읽은 줄 수)도 붙어 있었습니다.
> 이제 그 알림은 화면에 안 나옵니다. 필요하시면 다른 자리에 ⚠ 하나로 붙이겠습니다.

## 4. 단계 단추 — [정렬] [단계마다] [전체 구간]

```
전 (1.14)
[단계] [?] [단계마다 칸으로] [◀] [(전체 구간)▼] [▶] [눈금 0 = 단계 시작]

후 (1.15)
[정렬] [단계마다][전체 구간]
```

- 둘 중 하나만 눌립니다. **[단계마다]** = 단계 칸 나눠 보기, **[전체 구간]** = 시간 한 줄.
- 뺀 단추(한 단계 고르기 · ◀ ▶ · 눈금 0 · ?)의 기능은 `StepVm` 에 그대로 있어서 단추만
  다시 달면 됩니다. 단, 고르는 목록이 안 보이니 **두 단추는 고른 단계를 늘 풉니다**
  (안 풀면 왜 한 칸만 보이는지 알 수 없습니다).
- 단계가 없으면 두 단추가 잠기고, 마우스를 올리면 왜 잠겼는지 나옵니다.

## 5. 글자를 고치는 곳 — `src/LogScope.Core/Model/StepText.cs`

```csharp
public const string Caption = "정렬";        // 묶음 이름
public const string Each = "단계마다";        // 단계 칸으로 나누기 단추
public const string Whole = "전체 구간";      // 나누지 않고 한 줄 단추
public const string LabelBefore = "";         // 단계 이름 앞에 붙일 글
public const string LabelAfter = "";          // 단계 이름 뒤에 붙일 글
```

예: `LabelAfter = "단계"` → 단계 IO 값이 1, 2, 3 이면 `1단계` `2단계` `3단계`.
`LabelBefore = "S"` → `S1` `S2` `S3`. 같은 이름 둘째부터는 그 뒤에 ` (2)`.

- 이 이름은 그래프 칸 머리 · 커서 정보 · 히트맵 [가로를 단계로] 칸 머리에 똑같이 쓰입니다.
- 단계 **짝짓기**는 이 글자를 안 씁니다 (단계 IO 값 그대로 봄) — 고쳐도 짝은 안 바뀝니다.
- 고친 뒤 `build.bat` 으로 다시 빌드하면 됩니다.
- 시험도 이 글자를 거쳐 견주게 바꿔서, 고쳐도 시험이 깨지지 않습니다
  (`LabelAfter = "단계"` 로 바꿔 돌려 보고 861 통과를 확인한 뒤 되돌렸습니다).

## Windows 에서 확인 못 한 것

- XAML 은 여기서 컴파일되지 않습니다 (스텁 + 검사기만 통과).
- Delete 가 그래프를 누른 뒤에 먹는지 (검색 칸에 글을 쓰는 중에는 그 칸이 키를 받으므로
  커서가 안 지워지는 게 맞습니다).
- 검사: 컴파일 · 테스트 861 통과 · `check_sources` (x:Static 이름 틀리면 잡는 것도 확인) /
  `check_handlers` / `check_shadowing` 지적 없음.
