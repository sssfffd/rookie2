# 210 — 2.06 히트맵 0.1 초 칸의 "기록 없음"

## 요청 (요청 237)

> 그리고 지금 히트맵 0.1초로하면
> 0.101이랑 0.100이런거 비교안되서 그런지 기록 없음이라 뜨는 것들이 있는데 손봐주셈

## 까닭

히트맵은 칸마다 **이전 로그의 표본**을 모아 견줍니다. 기록 간격이 0.1 초인데 시각이 조금씩 흔들리면 (0.099 · 0.201 · 0.299 …)
0.1 초 칸 하나에 표본 둘이 들어가고 이웃 칸 (0.1 ~ 0.2) 은 **표본이 하나도 없어** "기록 없음" 이 됐습니다.
값을 못 견준 것이 아니라 그 칸에 이전 표본이 없었던 것.

```
시각   0.001  0.099 | (없음) | 0.201  0.299 | (없음) | …
칸     [0.0 ~ 0.1) |[0.1~0.2)| [0.2 ~ 0.3) |[0.3~0.4)|
```

## 고친 것

- 표본이 없는 칸이라도 **두 로그가 다 그 시각을 덮으면** 칸 가운데 시각의 값으로 견줌 — 아날로그는 이웃 표본 사이 보간,
  디지털 · 상태는 직전 값 (그래프에 그려지는 값과 같음). 허용 오차 · 초기 오차 무시도 같은 규칙.
- 한쪽 로그 밖 (로그가 일찍 끝남 등) 은 예전처럼 "이후 없음 · 이전 없음".
- 파일: `Analysis1/Heatmap/HeatmapBuilder.cs` (BuildRow)

## 확인

- 새 시험: 0.1 초 기록에 시각 ±1 ms 흔들림 · 0.1 초 칸 → 예전 코드에서는 118 칸 중 58 칸이 기록 없음 (재현), 고친 뒤 0 칸,
  값이 다른 구간은 그대로 차이. 시험 1161 통과, check 스크립트 통과.
- **Windows 에서 못 본 것**: 실제 로그로 본 0.1 초 히트맵.
