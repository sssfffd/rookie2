# 146 — 늘이기 · 튐 지우기 빼고, 오차를 눌러서 허용하게 · 히트맵 10 초 (1.55)

> 너가 적어준거에서 2번 4번은 안될듯 / 일단 단계 시간 차이가 나면 난거지 줄이고나 늘리면 안됨 / 그리고 아킹도 잡아내야지
> 차라리 이걸 오차라고 알리고 사용자가 해당 오차를 허용할지 안할지 선택하게 하면 되지 않을까? / 오차 부분을 알려주고
> 해당 오차를 클릭하면 허용으로 바꿀지 안할지 알려주는 거임 / 그리고 히트맵 10초 단위도 추가해야할듯
> 5번도 필요할꺼같네 / 3번은 다시 설명해주셈

## 바꾼 것
- 히트맵 칸 폭에 **10초** (자동 · 10초 · 1분 · 5분 · 10분 · 30분 · 1시간). 칸 4000 개 넘으면 폭을 넓힘 (있던 규칙)
  - `Analysis1/Heatmap/HeatmapVm.cs`, 테스트 2 개 (994 통과)

## 계획 고침 (코드 아직) — docs/ANALYSIS1-JUDGEMENT-GUIDE.md
- ② 단계 안 늘이기 **뺌** → 단계 길이 차이는 그대로 오차 항목
- ④ 짧은 튐 지우기 **뺌** → 아킹도 오차로 (평평한 구간에선 ③ 의 띠가 좁아 바로 잡힘)
- ⑤ 정도 재기 유지
- ③ 시간 여유 띠: 숫자 예 · 형광펜 비유로 다시 설명. 시간 여유 0 = 지금처럼
- ⑨ **오차 목록 + 눌러서 허용** (허용 안 함 · 이번만 · 앞으로도 [본 크기까지]) — 허용된 건 회색 "허용됨", 판정은 남은 오차로
  - 막는 장치: 본 크기까지만 허용, 허용됨도 목록에 남김, 설정에 허용 목록(지우기), 중요 IO 는 이번만, IO 단위 묶음

- Windows 에서 못 봄: 히트맵 10 초 칸 그림 (칸이 많을 때 그리는 속도)
