# 152 — 그룹 눌러도 IO 가 안 나오던 것 고침 · 화면 안 길어지게 · History 칸 작게 (1.61)

> 아니 이거 분석1에서 그룹 누르면 IO보여주는 창들이 뜨거나 밑에 IO목록이 열려야지 지금 그냥 그룹들만 전체보기가 되잖아
> 그리고 io목록 뜬다해서 전체창의 길이가 길어지면 안된다.
>
> 그리고 history남길 때 칸들 세로로 좀 작게 하셈

## 왜 IO 가 안 나왔나
1.59 에 그룹 · IO · 오차 줄의 값(`Ios` · `IsExpanded` · `Name` · `Summary` · `Items` …)을 **필드**로 적었음.
WPF 묶기(Binding)는 **속성만** 읽어서 IO 줄 목록이 비어 보였고, 칸 높이(속성)만 230 → 520 으로 늘어 "그룹만 전체보기" 가 됨.
Linux 시험은 C# 로 직접 읽어서 통과해 버림.

## 고친 것
| 무엇 | 전 | 후 |
|---|---|---|
| GroupSummaryVm · GroupIoVm 의 묶는 값 | 필드 | 속성 → 그룹 누르면 **바로 아래에 IO 줄**, IO 누르면 구간별 오차 |
| 그룹 칸 높이 | 펼치면 520 (메인 화면이 길어짐) | **230 고정** — IO · 오차 줄은 그 안에서 굴림 |
| History 칸 | 네 줄 (이름 / 판정·개수 / 요약 / 견준 것), 줄 하나 ~90 | **두 줄** (이름 · 판정 · 개수 / 요약), 줄 하나 ~56. 견준 것은 마우스를 올리면. 목록 상한 380 → 300 |
| 시험 | — | "이름이 Vm 으로 끝나는 형식에 공개 필드 없음" 검사 (27 개) — 같은 실수를 막음. ChannelListVm.All 도 속성으로 |
