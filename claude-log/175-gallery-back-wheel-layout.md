# 175 — 1.83 갤러리 뒤로가기 · 고른 그래프만 휠 확대 · 메인 배치

## 요청 (요청 202)

> 갤러리에서 IO 들 골라 보다가 한 IO 로 들어가면 다시 고르기 번거로움 → 뒤로가기.
> 휠이 바로 확대돼서 긴 창을 굴릴 수가 없음 → 그래프를 눌러 고른 뒤에만 휠 확대, 아니면 창 굴리기, 고른 그래프는 테두리.
> 종합 분석 결과는 분석들 아래로. 분석 1 이 메인이니 크게, 2 · 3 은 그 밑에.

## 한 것

| 무엇 | 어떻게 | 파일 |
|---|---|---|
| 갤러리 → IO 하나 | 칸을 **두 번** 누르면 그 IO 하나만 Lane (한 번 누르기는 고르기로 씀) | `GraphCanvas.cs` |
| 뒤로가기 | 들어가기 전 고른 IO 이름을 `GraphVm.RememberBack()` 에 두고, `[◀ 갤러리로]` 가 `TakeBack()` 으로 되살림. 보기를 손으로 바꾸면 `ForgetBack()` | `GraphVm.cs`, `GraphView.xaml(.cs)`, `GraphTexts.cs` |
| 고른 그래프 | 한 번 누르면 `_selectedKey` = 그 자리 그래프 (Lane 줄 · 갤러리 칸 · 겹쳐보기 판), 그래프 밖을 누르면 풀림. 그릴 때 2 px 강조색 테두리 | `GraphCanvas.cs` |
| 휠 | 고른 그래프 위 → 예전 확대 (모든 줄 같이 · 단계 칸 · Shift = 값). 그 밖 → 목록을 60 px × 칸 수 만큼 굴림, 굴릴 것이 없으면 부모가 굴리게 둠 | `GraphCanvas.cs` |
| 메인 배치 | 칸 패널을 2 × 2 Grid 로: 분석 1 = 0 줄 두 칸 통째 (MinHeight 390), 분석 2 = 1 줄 왼쪽, 3 = 1 줄 오른쪽 (300) | `MainView.xaml`, `AnalysisCardVm.cs` (`LayoutRow/Column/Span`, `CardMinHeight`) |
| 종합 분석 결과 | 분석 칸들 아래, 저장된 분석 위로 옮김 | `MainView.xaml` |

```

┌──────── 종합 분석 결과 (LLM) ────────┐
```

## 확인

- 시험 1139 통과 (새: 갤러리 → IO 하나 → 뒤로 = 고른 셋 그대로 · 손으로 갤러리 = 뒤로가기 사라짐 · 메인 칸 자리).
- check_sources / handlers / shadowing 통과, 실제 csc (C# 7.3, .NET 4.6.1 참조) 빌드 통과, XAML 형식 확인.
- **Windows 에서 못 본 것**: 메인 배치 모양, 테두리 모양, 휠 굴리기 (특히 Lane · 갤러리가 화면보다 길 때 / 짧아 부모 창이 굴려야 할 때), 두 번 누르기.
