# 89 — 점수 키우기 (분석 2 낱말과 같게) · 이전/이후 위로

> 그 메인화면 파일들 넣었을때 이전 이후 위치 조금 더 올려주고 분석 1 점수 키워주셈
> 오른쪽 분석 2 PASS 글자 사이즈랑 맞추면 될듯

## 1. 점수 크기

1.06 부터 분석 1 점수와 분석 2 `PASS` 는 **둘 다 24pt** 였습니다 (코드상 같은 값
`ScoreSize`). 그래도 작아 보였다고 하셔서 "키우고 맞추기" 로 읽고 **셋 다 30pt**
로 올렸습니다.

| | 1.08 | 1.09 |
|---|---|---|
| 분석 1 점수 `100` | 24 | **30** |
| 분석 2 낱말 `PASS` | 24 | **30** |
| 분석 2 차이 개수 | 24 (따로 적힘) | **30** (`ScoreSize` 를 같이 씀 — 하나만 바뀌는 일 없게) |

> 혹시 지금 보시는 프로그램이 1.06 전 것이면, 그때는 분석 1 점수가 34 · PASS 가
> 24 였습니다. 그 크기 차이를 보신 거라면 이번 것으로 맞춰집니다.

30 보다 키우지 않은 까닭: `WARNING  차이 발생 152 개` 가 30pt 에서 약 290 px 입니다.
창 폭 1280 이면 칸 안쪽이 약 360 px 이라 들어가고, 1024 처럼 좁으면 개수가
잘릴 수 있습니다.

## 2. 이전/이후 위로

```
전 (1.08)                     후 (1.09)
┌ 분석 1 ─────────────┐       ┌ 분석 1 ─────────────┐
│ 100 / 100           │       │ 100 / 100           │
│                     │ ← 빈 줄│ ● 이전  a.csv  …    │
│ ● 이전  a.csv  …    │       │ ● 이후  b.csv  …    │
```

1.06 에 점수 자리 높이를 54 로 고정했는데, 그 안에 **점수 아래 글 한 줄** 자리가
들어 있었습니다. 파일을 넣으면 그 글이 비어서 이전/이후 위에 빈 줄이 남았습니다.

- 점수 아래 글("Log 파일을 비교한 후 점수가 나옵니다")을 **점수 오른쪽**으로
  옮겼습니다 (좁으면 … 로 자르고 마우스를 올리면 다 보임).
- 점수 자리 높이 = 점수 한 줄(42).
- 파일 줄 위 여백 10 → 4.

칸끼리 줄 맞춤(1.06)은 그대로입니다 — 높이가 고정이라 분석 1·2 의 이전 줄이
같은 높이에서 시작합니다.

## Windows 에서 확인 못 한 것

- XAML 은 여기서 컴파일되지 않습니다 (스텁 + 검사기만 통과).
- 42 는 Segoe UI 30pt 한 줄 높이를 어림한 값입니다. 점수 위가 잘리면 올리고,
  이전 줄 위가 아직 비어 보이면 `Margin="0,4,0,0"` 을 0 으로 내리면 됩니다.
- 검사: 컴파일 · 테스트 859 통과 · `check_sources` / `check_handlers` /
  `check_shadowing` 지적 없음.
