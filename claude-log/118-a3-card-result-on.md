# 118 — 분석 3 결과를 메인 칸에 다시 띄움

> a3resultoncard는 true로 바꿔야 될듯? 지금 분석3 내에서 프로그램돌린게 메인화면에 안뜸

1.36 에 `MainVm.A3ResultOnCard = false` 로 결과 자리를 비웠더니, 분석 3 안에서 돌린 결과(`Publish`)도
메인 칸에 안 떴습니다. 1.37 에 `true` 로 되돌렸습니다.

| | 1.36 | 1.37 |
|---|---|---|
| `Publish` 한 결과 (낱말 · 점수 · 개수 · 요약 줄) | 안 뜸 | **뜸** |
| 결과가 오기 전 | 빈 칸 | 빈 칸 (전의 "아직 결과가 없습니다…" 안내 글은 다시 넣지 않음) |

확인: 리눅스 컴파일 · 시험 911 통과, 실제 C# 7.3 컴파일러 오류 0. Windows 에서 분석 3 을 돌려 메인 칸에
뜨는지 확인 필요. 그래도 안 뜨면 분석 3 코드가 `Analysis3Link.Publish(r)` 를 부르는지 확인 (117 의 지도).
