## 1. 분석 1 카드 (1.21)

```
┌ 분석 1 ───────────────────────┐ ┌ 분석 2 ───────────────────────┐
│ 100 / 100   차이 발생 12 개    │ │ FAIL        차이 발생 152 개   │  ← 같은 자리 · 같은 30pt
│ ● 이전  a.csv …               │ │ ● 이전  before.sql …          │  ← 줄 맞춤 그대로
│ ● 이후  b.csv …               │ │ ● 이후  after.sql …           │
│ 요약 …                        │ │ 요약 …                        │  ← 숫자 칸이 빠져서 요약도 같은 높이
```

- 분석 2 의 개수와 **같은 칸(VerdictCount)** 을 써서 자리 · 크기 · 색(점수 색)이 같습니다.
  점수 줄 높이는 1.09 에 고정해 둔 그대로라 이전/이후 줄 맞춤이 안 깨집니다.
- "차이 난 IO 12/180" · "한쪽에만 있는 IO 3개" 숫자 칸은 뺐습니다. 칸이 비면 그 줄째
  안 보입니다. 한쪽에만 있는 IO 는 대시보드에 목록으로 남아 있습니다.
- 바뀐 파일: `App/Shell/AnalysisCardVm.cs` (`SetCount`) · `MainVm.cs` · `README.md`.
