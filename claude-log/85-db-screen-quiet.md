# 85 — 분석 2 화면의 글 걷어 내기 · 맨 아래 이전/이후 줄 숨기기

> 그리고 분석 2 안에 들어갔을 때
> 이전 이후 창 밑이랑 차이 목록창 위에
> 글자들 여러개 뜨잖아
> 차이 몇개 발생 이런거 싹다 없애줘
> 그리고 창들 맨 밑에 이전 이후 뜨는 것도 없애주고

## 1. 두 칸과 차이 목록 사이 — 비움

```
전 (1.04)                                        후 (1.05)
┌ ● 이전 ─────┐ ┌ ● 이후 ─────┐                  ┌ ● 이전 ─────┐ ┌ ● 이후 ─────┐
└─────────────┘ └─────────────┘                  └─────────────┘ └─────────────┘
폴더를 넣으면 그 안의 … (자리 설명)               ┌ 차이 목록  ⚠  보기 [..][..][..] ┐
WARNING — 차이 발생 3개 — TEMP_MAX …  (판정)
차이 발생 : 3개   없어진 IO : 0개 …  (읽은 행 …)
old.csv — 6 개 열 중 3 번(io)으로 … (읽기 알림)
┌ 차이 목록  1,234 줄 (차이 전체)  보기 … ┐
```

| 뺀 것 | 이제 어디서 보나 |
|---|---|
| 자리 설명 ("폴더를 넣으면 …") | 칸 위 머리글 · [폴더] [파일] 단추 풍선말 |
| 판정 + 까닭 | 메인 화면 분석 2 칸 |
| `차이 발생 : N개 · 없어진 IO · 새로 생긴 IO · 읽은 행` | 차이 개수는 메인 칸. 없어진·생긴 IO 는 `[차이 전체]` 목록의 줄로 |
| 목록 머리의 `N 줄 (차이 전체)` | 없음 (목록 스크롤로 보임) |
| 읽기 알림 (못 읽은 파일 · 안 본 열 · 키 없는 표) | 목록 머리의 **⚠** (있을 때만, 마우스를 올리면 다 보임) |

**⚠ 하나는 남겼습니다.** 읽기 알림까지 아예 지우면 파일 하나를 못 읽어도
모르고 지나가고, 그 파일의 IO 가 전부 "없어진 IO" 로 잡혀 판정이 틀립니다.
없을 때는 안 보입니다.

뷰모델에서도 `Summary` · `Overview` · `PathText` · `LineText` 를 지웠습니다
(보여 줄 데가 없는 글을 만들고 있으면 다음 사람이 "어디 뜨지?" 를 찾게 됩니다).
`DbVerdict.Why` · `DbDiffList.Headline` 은 Db 쪽에 그대로 있습니다 (테스트가 씀).

## 2. 창 맨 아래 "이전: … | 이후: …" — 분석 1 에서만

그 줄은 **로그 두 개**(이름 · 채널 · 표본 · 읽기 알림)를 적는 줄이라 분석 2 (DB)
에서는 엉뚱한 파일 이야기였습니다. 메인 화면은 칸마다 파일이 이미 적혀
있어서 거기서도 숨겼습니다. 분석 1 (대시보드 · 그래프 · 히트맵)에서는
그대로 보입니다 — 로그 읽기 알림이 거기 뜨기 때문입니다.

## Windows 에서 확인 못 한 것

- XAML 은 여기서 컴파일되지 않습니다 (스텁 + 검사기만 통과).
- ⚠ 풍선말이 여러 줄 알림을 다 보여 주는지 (WPF 기본 풍선말은 줄바꿈을 지킵니다).
- 검사: 컴파일 · 테스트 841 통과 · `check_sources` / `check_handlers` /
  `check_shadowing` 지적 없음.
