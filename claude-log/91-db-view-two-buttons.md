# 91 — 분석 2 보기 단추: [차이 발생] · [전체]

> 분석 2안에 값이 달라진것만 버튼 없애고
> 차이 전체 대신
> 차이 발생 / 전체 로 버튼 나눠주셈

## 바뀐 것

```
전 (1.10)                                     후 (1.11)
보기 [값이 달라진 것만][차이 전체][모든 IO]      보기 [차이 발생][전체]
```

| 단추 | 보이는 줄 | 전 이름 |
|---|---|---|
| **차이 발생** (기본) | 값 차이(빨강) · 생김 · 없어짐 · 열 차이 | 차이 전체 |
| **전체** | 위에 더해 두 쪽이 같은 IO 까지 | 모든 IO |

- `[값이 달라진 것만]` 은 뺐습니다. 빨간 줄은 `[차이 발생]` 안에 그대로 있습니다.
- `[.CSV로 저장]` 은 전처럼 **보고 있는 범위 그대로** 내보냅니다.
- 판정·개수(메인 화면)는 어느 단추를 골라도 그대로입니다.
- 안내 글도 새 이름으로 바꿨습니다 — 목록이 비었을 때 "[전체] 로 보면 같은 IO
  도 줄로 보입니다", 메인 칸 "… 분석 2 화면 [차이 발생] 에서 볼 수 있습니다".
