# 86 — 점수 아래 글 빼기 · 분석 1·2 파일 줄 맞추기 · 분석 2 단추 이름

> 데이터 넣었을때 메인화면 분석1에 이상없음 이런 글자도 치워주고
> 이전 이후 파일 뜨는 거 분석 2랑 줄 맞춤 해주셈
> 점수 크기를 줄이면 될듯?
> 그리고 분석 2화면에서 견줄 db글자들 없애주고
>
> DB 읽기 대신에 데이터 읽기로 바꿔주고
> 목록 csv 저장 대신에 .CSV로 저장으로 바꿔줘

## 1. 점수 아래 "이상 없음" — 뺌

점수가 나온 뒤 아래에 적던 `이상 없음 · 확인 필요 · 점검 필요` 를 뺐습니다.
점수 색과 화면 오른쪽 아래 색 설명이 같은 말을 합니다.
로그를 넣기 **전**의 "Log 파일을 비교한 후 점수가 나옵니다" 는 남겨 뒀습니다
(넣었을 때 얘기만 하셔서). 그것도 빼려면 `AnalysisCardVm.ScoreNote` 한 줄입니다.

## 2. 이전/이후 줄 맞추기 — 점수 크기 + 자리 높이 고정

```
전                                        후
┌ 분석 1 ─────┐ ┌ 분석 2 ─────┐           ┌ 분석 1 ─────┐ ┌ 분석 2 ─────┐
│ 100 / 100   │ │ FAIL 차이 3 │           │ 100 / 100   │ │ FAIL 차이 3 │
│ (34pt)      │ │ ● 이전 …    │           │             │ │             │
│ 이상 없음    │ │ ● 이후 …    │           │ ● 이전 …    │ │ ● 이전 …    │
│ ● 이전 …    │ │             │           │ ● 이후 …    │ │ ● 이후 …    │
│ ● 이후 …    │                           
```

말씀대로 **점수 크기를 34 → 24pt** (판정 낱말과 같은 크기)로 줄였습니다.
그것만으로는 모자라서 하나 더 했습니다:

- **점수 자리 높이를 54 로 고정.** 점수 아래 글이 있는 칸(로그 넣기 전 분석 1)과
  없는 칸, DB 를 아직 안 읽어 점수 줄이 아예 없는 분석 2 가 섞여도 이전/이후
  줄이 같은 높이에서 시작합니다.
- 점수 아래 글은 한 줄로 자릅니다 (두 줄이 되면 고정 높이를 넘습니다).

## 3. 분석 2 화면

| 전 | 후 |
|---|---|
| `견줄 DB    (칸에 끌어다 놓으면 들어갑니다. 폴더도 파일도 됩니다)` | 뺌 |
| `[DB 읽기]` | `[데이터 읽기]` |
| `[목록 CSV 저장]` | `[.CSV로 저장]` |

"[DB 읽기] 를 눌러 주세요" 같은 안내 글도 `[데이터 읽기]` 로 다 바꿨습니다
(단추 이름과 안내가 다르면 못 찾습니다). [데이터 읽기] 풍선말은 "아래 두 칸을
읽어 견줍니다" (칸이 단추 아래에 있습니다).

## Windows 에서 확인 못 한 것

- XAML 은 여기서 컴파일되지 않습니다 (스텁 + 검사기만 통과).
- 54 는 맑은 고딕 24pt 한 줄 + 11pt 한 줄을 어림한 값입니다. 점수 아래가
  잘려 보이면 `MainView.xaml` 의 `Height="54"` 를 올리고, 이전 줄 위가 너무
  비어 보이면 내리면 됩니다.
- 검사: 컴파일 · 테스트 841 통과 · `check_sources` / `check_handlers` /
  `check_shadowing` 지적 없음.
