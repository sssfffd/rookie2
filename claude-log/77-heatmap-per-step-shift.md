# 77 — 히트맵이 "정렬한 것 기준" 으로 오차를 못 잡던 것

> 그리고 히트맵은 정렬한것 기준으로 오차 잘 안잡히는거 같은데 맞아?

**맞습니다.** 짚어 주신 자리가 정확합니다.

## 무엇이 틀렸나

히트맵은 밀기 값을 **하나**만 받아서 줄 전체에 썼습니다.

```csharp
double shift = opt.Shift;              // 하나
for (표본마다)
{
    double ta = t - shift;             // 전부 이 값으로 읽음
    int k = 어느 칸인지;
}
```

0.91 에 [가로를 단계로] 를 만들면서 **칸만 단계로 잘랐습니다.** 밀기 값은
그대로 하나였습니다. 그러면

- 그 하나에 맞는 단계(보통 첫 단계)만 제대로 견주고,
- **나머지 칸은 어긋난 채 견줍니다.**

공정이 중간에 조금 늘어진 로그가 늘 이 모양입니다 — 뒤 단계가 앞 단계보다
더 밀립니다. 그래서 **차이가 없는데 있다고 나오거나, 있는데 묻혔습니다.**
0.93 에 그래프를 칸으로 나눌 때는 칸마다 제 밀기 값을 줬는데, 히트맵은
같이 못 고쳤습니다.

## 고친 것

칸마다 그 단계의 밀기 값을 들고 다니게 하고(`HeatBuckets._shifts`), 세는
쪽을 **칸 단위**로 돌게 바꿨습니다.

```csharp
for (칸마다)
{
    double shiftK = cuts.ShiftOf(k, shift);     // 그 단계의 값
    if (밀기 값이 바뀌었으면) j = 이후 로그에서 그 자리를 다시 찾기;
    for (그 칸의 표본마다) { double ta = t - shiftK; … }
}
```

**자리를 다시 찾는 까닭**: 밀기 값이 칸마다 다르면 이후 로그를 읽는 자리가
칸이 바뀔 때 **뒤로 갈 수 있습니다** (뒤 단계가 더 밀리면 `t - shift` 가
작아집니다). 앞으로만 미는 자리표로는 못 찾습니다. 그래서 밀기 값이 바뀔
때만 이진 탐색으로 다시 잡습니다 — 시간 폭으로 자르면 한 번뿐이라 전과
같은 속도입니다. 표본은 여전히 한 번씩만 봅니다.

겹치는 구간을 자르는 방식도 바꿨습니다. 전에는 밀기 값 하나로 두 로그가
겹치는 구간을 먼저 자르고 그 안에서 칸을 만들었습니다 — 그러면 **그 하나에
안 맞는 단계가 통째로 잘려 나갑니다.** 단계로 자를 때는 이전 로그의 단계
구간을 그대로 칸으로 쓰고, 이후 로그에 기록이 없는 표본만 건너뜁니다.

## 시험으로 못을 박았습니다

단계마다 **다르게** 밀린 로그 한 쌍을 만들었습니다 — A 는 100, B 는 105,
C 는 110 만큼. PV 는 단계마다 0 에서 다시 올라가는 톱니입니다.

| 어떻게 견줬나 | 결과 |
|---|---|
| 칸마다 그 단계로 (0.96) | 세 칸 다 **차이 0** (제대로 맞췄으니 톱니가 겹침) |
| 밀기 값 하나로 (-100) | PV 가 **차이 남** (B 는 5 초, C 는 10 초 어긋남) |

앞의 줄이 고친 뒤의 모습이고, 뒤의 줄이 0.95 까지 단계 칸에서 벌어지던
일입니다. `통과 801 / 실패 0`.

## 아직 밀기 값 하나인 곳 — 적어 뒀습니다

**대시보드와 점수(DiffEngine)** 는 아직 밀기 값 하나로 셉니다. 히트맵만
칸마다 맞춥니다. 그 말을 두 자리에 적어 뒀습니다.

- 그래프 아래 줄: "히트맵도 [가로를 단계로] 를 켜면 칸마다 그 단계로 맞춰
  셉니다. 대시보드와 점수는 아직 밀기 값 하나로 셉니다."
- 히트맵 요약 줄: [가로를 단계로] 가 꺼져 있고 그래프에서 단계를 골라
  뒀으면 — "고른 단계(2. 가열)의 밀기 값으로 전체를 견줬습니다 — 다른
  단계는 어긋나 보일 수 있습니다."

대시보드·점수까지 단계별로 셈하려면 `DiffEngine` 도 같은 모양으로 고치면
됩니다 (칸 단위로 돌면서 밀기 값을 바꿔 끼우기). 말씀해 주시면 하겠습니다 —
그쪽은 점수와 저장된 분석 기록까지 뜻이 달라지는 자리라 묶어서 해야 합니다.

## 아직 못 본 것

고친 셈은 시험으로 봤지만, **실제 로그로 돌려 보지는 못했습니다.**
[가로를 단계로] 를 켜고 끄며 같은 로그를 보시면 차이가 바로 보일 겁니다 —
전에는 뒤 단계가 빨갛게 떴다면 이제는 가라앉아야 맞습니다 (또는 그 반대로,
묻혀 있던 차이가 드러납니다).
