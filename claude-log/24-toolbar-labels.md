# 24 — 도구 줄 이름 정리, 두 보기 방식은 하나만

> 요청: "시간축 값축의 확대 축소를 + -로 전체, 되돌리기를 초기화로
> 시간 축은 Time Scale / 값축은 Value Scale로 표현을 바꿔줘
> 그리고 차이 음영은 차이 영역 표시로
> 벌려 그리기는 파형 분리 보기로 바꿔주고
> 둘 중에 하나만 선택되게 해줘"

---

## 1. 이름

| 묶음 | 전 | 후 |
|---|---|---|
| 시간축 → **Time Scale** | [전체] [확대] [축소] | **[+] [−] [초기화]** |
| 값 축 → **Value Scale** | [확대] [축소] [구간 맞춤] [되돌리기] [계속 맞춤] | **[+] [−] [초기화]** [구간 맞춤] [계속 맞춤] |
| 비교 | [차이 음영] | **[차이 영역 표시]** |
| 비교 | [벌려 그리기] | **[파형 분리 보기]** |

`+` 와 `−` 는 **글자가 아니라 기호**라 폭이 항상 같습니다. "확대" 와
"축소" 처럼 글자 수가 다른 것을 나란히 두면 단추 폭이 들쭉날쭉해서 두 묶음이
서로 어긋나 보였습니다. 폭을 30 으로 고정해 두 묶음의 단추가 세로로
나란히 섭니다.

```
┌ Time Scale ─────────────────┐
│ [ + ] [ − ] [초기화]         │
└─────────────────────────────┘
┌ Value Scale ────────────────────────────────────┐
│ [ + ] [ − ] [초기화] [구간 맞춤] [계속 맞춤]     │
└─────────────────────────────────────────────────┘
```

무슨 뜻인지는 풍선 도움말에 그대로 있습니다 — `+` 에 마우스를 올리면
"시간축 확대. 휠로도 됩니다." 가 나옵니다.

글자가 줄어서 도구 줄도 조금 더 짧아졌습니다. 3 줄 상한은 그대로입니다.

---

## 2. 둘 중에 하나만

**[차이 영역 표시] 와 [파형 분리 보기] 는 같이 켜지지 않습니다.**

이유가 있습니다. 파형 분리 보기는 이전 선과 이후 선을 위아래로 조금
**벌려** 그립니다. 그 상태에서 두 선 사이를 칠하면,

```
같이 켜면                        하나만 켜면
      ╭─── 이후                        ╭─── 이후
   ▓▓▓│▓▓▓  ← 칠해진 넓이 =         ▓▓▓│▓▓▓  ← 칠해진 넓이 =
      ╰─── 이전     값 차이            ╰─── 이전    값 차이
                  + 벌린 간격
```

칠해진 넓이가 **"값 차이 + 벌린 간격"** 이 됩니다. 눈으로 재는 넓이가
세로 눈금과 안 맞게 되는데, 그건 그래프가 거짓말을 하는 것입니다.

### 어떻게 막았나

라디오 단추로 바꾸지 않고 **토글 두 개를 그대로 두되 서로 끄게** 했습니다.

```csharp
public bool ShadeDifference
{
    set
    {
        S.ShadeDifference = value;
        if (value && S.SeparateTraces) { S.SeparateTraces = false; Raise("SeparateTraces"); }
        ...
    }
}
```

라디오로 만들면 **둘 다 끌 수가 없습니다.** 아무 장식 없이 선 두 개만 보고
싶을 때가 있어서, 켜져 있는 것을 다시 누르면 꺼지는 쪽을 골랐습니다.

정리하면 — **셋 중 하나**입니다.

```
차이 영역만        파형 분리만        둘 다 끄기
```

### 옛 설정 파일

전에는 둘을 따로 켤 수 있었으니, 둘 다 켜진 설정 파일이 남아 있을 수
있습니다. 그대로 두면 **화면에서는 만들 수 없는 상태**로 뜹니다. 읽을 때
차이 영역 쪽을 남기고 파형 분리를 끕니다.
