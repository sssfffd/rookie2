# 88 — 분석 2: 차이를 빨간 글씨로 (+N / a → b) · 메인은 색만

> 그리고 분석 2에서 차이가 있으면 숫자는 (+- 몇으로) 빨간색 글씨로 추가 표시해주고
> 글자는 ( a -> b) 느낌으로 추가표시해주셈
> 메인 화면에서는 다 넣으면 길어지니까 빨간색으로 색칠만 해주고

## 분석 2 목록

```
IO명        이전 value   이후 value
TEMP_MAX    1            4  (+3)               ← 빨간 굵은 글씨
PRES_SET    2.5          2.25  (-0.25)
VALVE_1     OPEN         CLOSE  (OPEN → CLOSE)
ALARM_TXT   NULL         3  (NULL → 3)          ← 한쪽만 숫자면 글자 꼴
```

- **이후 value 칸 안**, 값 바로 옆에 붙였습니다. 칸을 따로 두면 눈이 오른쪽
  끝까지 가야 "무엇이 얼마나" 가 이어집니다. 그래서 그 칸 폭을 220 → 300 으로
  넓혔습니다.
- 값이 **달라진 줄**(옅은 빨강 줄)에만 붙습니다. 생김·없어짐·같음 줄에는 없습니다.
- 숫자: `이후 − 이전` 에 `+` / `-` 를 붙입니다. `decimal` 로 빼서 `0.1 → 0.3` 이
  `(+0.2)` 로 적힙니다 (`double` 이면 `0.19999999999999998`).
- 숫자로는 같은데 글자만 다르면(`1.0` → `1`) `(+0)` 대신 `(1.0 → 1)` — 0 이라고
  적으면 왜 칠해졌는지 알 수 없습니다.
- 화살표는 메인 요약과 같은 `→` 입니다 (`DbChangedIo.Arrow` 한 곳).
- **CSV 에는 넣지 않았습니다.** 칸이 늘면 엑셀에서 쓰던 열 자리가 밀립니다.
  넣으시려면 말씀해 주세요.

## 메인 화면

요약 칸의 `1 → 2` 를 **빨간 글씨로 칠만** 했습니다. `(+1)` 은 안 붙입니다.
분석 1 의 줄(`3/20` 같은 수)은 그대로 회색입니다 — `CardLineVm.ValueIsChange`
가 참인 줄만 빨갛게 됩니다 (분석 1 수까지 빨개지면 빨강의 뜻이 흐려집니다).
