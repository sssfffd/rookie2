# 69 — DB 쪽에서 안 쓰는 것 걷어내기 (0.88)

## 주신 말

> 분석 2 db관련 코드에서 사용되지 않는 부분이나 필요 없는 부분들 지워서
> 코드좀 간결하게 만들여줘(단 개발자가 코드보고 의도 파악 쉽도록)

## 어떻게 골랐나

눈으로 고르면 **쓰는 것을 지웁니다.** 그래서 "앱에서 닿을 수 있는가" 를
기준으로 찾았습니다. 의심 가는 멤버마다 쓰는 곳을 세고, 주석과 선언
줄은 셈에서 뺐습니다.

그 결과 셋으로 갈렸습니다.

| | 어떻게 |
|---|---|
| **앱이 못 닿는 것** | 지웠습니다 |
| **시험만 쓰는 것** | 남겼습니다 (까닭은 아래) |
| **앱이 쓰는 것** | 그대로 |

## 지운 것

### 1) 되돌리는 방향 (`SqlScript.Direction`) — 이게 가장 컸습니다

맞추는 SQL 은 두 방향을 만들 수 있었습니다. 0.71 에 화면의 고르는 칸을
뺀 뒤로 **부르는 쪽이 없었습니다.** 그런데 그 때문에 `DbSql.cs` 의
**열다섯 군데**가 이렇게 갈라져 있었습니다.

```csharp
bool missingHere = (toAfter && cd.Change == DbChange.OnlyAfter)
                || (!toAfter && cd.Change == DbChange.OnlyBefore);
```

읽는 사람이 매번 두 경우를 머리에 올려야 했습니다. 지금은 이렇습니다.

```csharp
if (cd.Change == DbChange.OnlyAfter)
```

방향이 하나뿐이라는 것은 머리 주석에 적었고, 만든 글의 첫 줄에도
그대로 적힙니다.

### 2) `DbCreateSql` (표 정의를 `CREATE TABLE` 글로)

**0.64 에 그 단추를 뺀 뒤로 앱이 부르지 않았습니다.** 시험만 살려 두고
있었습니다. 115 줄 + 시험 55 줄을 지웠습니다.

### 3) `Options.IncludeTableCreateDrop` 과 `Create()`

이 깃발을 켜는 곳이 **아무 데도 없었습니다** (시험조차). 그것이 지키던
`Create()` 도 같이 지웠습니다.

### 4) 제가 남긴 쓰레기

- `if (wide > 0) { }` — 0.87 에 제가 남긴 빈 문장입니다
- `int commentsLength = ...` — 읽어서 안 쓰는 지역 변수 (주석으로 바꿨습니다)

## 남긴 것 — 그리고 왜

### `Options` 의 상한들 (`MaxLines` · `MaxRowStatements` …)

앱은 **전부 기본값만** 씁니다. 지우고 상수로 박으면 더 짧아집니다.
**그런데 지우면 안 됩니다** — 시험이 상한에 걸리는 모습을 보려고 이
자리를 씁니다. 없으면 상한을 보기 위해 5 만 줄짜리 자료를 만들어야
합니다. "왜 남겼나" 를 그 자리에 적어 두었습니다.

### `.frm` 읽기와 `mysqldump` · `ibd2sdi` (`DbReadMysql.cs`, 991 줄)

**DB 쪽 코드의 23 % 입니다.** 지금은 `.csv` 로 쓰고 계시니 안 닿는
길이지만, **설정 창의 [DB 도구] 와 폴더 읽기에서 닿습니다** — 쓰시던
기능이라 제 판단으로 지우지 않았습니다.

빼면 991 줄이 한 번에 없어집니다. 원하시면 말씀해 주세요.

## 고친 것 — 거짓말이 된 안내 글

상한에 걸렸을 때 나오는 말이 이랬습니다.

> 왼쪽에서 표를 골라 **[고른 표만]** 으로 보거나, CSV 로 내보내 보세요.

**[고른 표만] 은 0.64 에 없어진 단추입니다.** 처음엔 "CSV 로 내보내
보세요 (CSV 에는 이 상한이 없습니다)" 로 고쳤는데, 코드를 보니
**CSV 저장도 같은 상한을 거칩니다.** 거짓말을 하나 더 쓴 셈이라 사실대로
바꿨습니다 — "CSV 로 내보내도 같은 상한이 걸립니다. 견줄 자리를
좁혀 주세요."

## 읽기 쉽게 바꾼 것

0.87 에 제가 `CsvTableReader.Read` 안에 50 줄을 늘어놓았습니다. 이름
있는 단계로 뽑았습니다 (0.74 에서 배운 것).

```
Read  →  Head(t, cells, count)   첫 줄로 열을 세우고 "어느 자리를 읽을지" 를 돌려줌
         Skipped(...)            안 읽은 열 이름 (조용히 버리지 않으려고)
         Name(...) · NewColumn(...)
```

`Read` 본문이 20 줄로 줄어 "읽고 → 열 세우고 → 행 담기" 가 한눈에
보입니다.
