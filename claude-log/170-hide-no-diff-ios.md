# 170 — 그룹을 펼쳤을 때 차이 없는 IO 는 안 보이게 (1.79)

> 분석 1쪽에 Io그룹눌렀을때 차이 없는건 안떴으면 하네

메인 화면 분석 1 칸에서 그룹을 누르면 펼쳐지는 IO 줄:

| | 1.78 | 1.79 |
|---|---|---|
| 차이 없는 IO ("오차 없음") | 보임 | **안 보임** |
| 오차가 있는 IO | 보임 | 보임 |
| 허용해 둔 오차만 있는 IO ("허용됨 N") | 보임 | 보임 (그 창에서 허용을 풀 수 있게) |
| 차이 있는 IO 가 하나도 없는 그룹 | 펼치면 "오차 없음" 줄들 | 펼치지 않음 — 누르면 예전처럼 그 그룹을 그래프로 |

그룹 줄의 "N / M 달라짐" 수는 그대로 (M = 그룹의 IO 수).

## 확인
- 테스트 1129 통과 (펼친 줄: 여섯 → 차이 있는 넷), 실제 csc 7.3 오류 0, 검사 스크립트 통과
- **Windows 에서 못 봄** (화면)
