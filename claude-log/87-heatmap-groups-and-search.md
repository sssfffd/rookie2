# 87 — 히트맵에 검색 · 그래프와 같은 그룹으로 나누기

> 그리고 히트맵에서 그래프처럼 검색으로 볼 수 있게 해주고
> 그룹을 똑같이 사용해서 나눠주셈

## 화면

```
[히트맵 다시 계산]  [ temp        ] [검색 지우기]  [가로를 단계로] …

차이가 난 IO  4개   │ 10:00 │ 10:01 │ …
▼ 온도         2개  │       │       │      ← 그룹 이름 줄 (누르면 ▶ 로 접힘)
  TEMP_C        3칸 │ 1.2%  │ 정상  │
  TEMP_A        1칸 │ 정상  │ 0.4%  │
▼ 압력         1개  │       │       │
  PRES_B        2칸 │ …
▼ 그룹에 없는 IO 1개 │       │       │
  X_LONE        1칸 │ …
```

## 그룹 — 그래프와 "똑같이"

| | 그래프 IO 목록 | 히트맵 |
|---|---|---|
| 그룹 | 설정의 그룹 | **같은 것** (사본 아님) |
| 그룹 차례 | 설정 차례 | 같음 |
| IO 가 그룹 둘에 | 앞 그룹에만 | 같음 |
| 그룹에 없는 IO | 맨 아래 "그룹에 없는 IO" | 같음 |
| 그룹 안 차례 | 그룹에 넣은 차례 | **히트맵 차례** (많이 벌어진 것이 위) |
| 빈 그룹 | 이름 줄 보임 (검색 중엔 숨김) | **늘 숨김** (차이 난 IO 가 없는 그룹) |
| 접기 | GroupDef.Expanded (저장됨) | **따로** (히트맵 안에서만) |

다르게 한 셋의 까닭:
- **그룹 안 차례** — 히트맵은 "어디가 제일 나쁜가" 를 보는 화면이라, 그룹 안에서도
  나쁜 것이 위에 있어야 합니다.
- **빈 그룹 숨김** — 히트맵에는 차이 난 IO 만 옵니다. 아무 일 없던 그룹 이름이
  줄줄이 깔리면 볼 줄이 아래로 밀립니다.
- **접기 따로** — 히트맵에서 접었는데 그래프 목록까지 접히면 거기서는 왜
  접혔는지 모릅니다.

그래프에서 그룹을 만들거나 IO 를 옮기면 히트맵도 바로 다시 나뉩니다
(`ShellWindow.OnGroupsChanged` → `HeatmapView.RefreshGroups`). **다시 계산은
안 합니다** — 이미 센 줄을 늘어놓기만 합니다.

## 검색

그래프 검색과 같은 규칙입니다 (이름에 그 글자가 들면, 대소문자 안 가림).
치는 대로 바로 걸러집니다 (다시 계산 없음). 맞는 IO 가 없는 그룹은 사라지고,
하나도 없으면 판 가운데에 `"xxx" 이(가) 이름에 든 IO 가 없습니다.` 를 적습니다.
왼쪽 위 "차이가 난 IO N개" 는 걸러진 뒤의 수입니다.

메인 화면에서 그룹을 눌러 넘어오는 "한 그룹만 보기" 는 그대로입니다 (그건
계산부터 그 그룹만 합니다).
