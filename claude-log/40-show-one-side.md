# 40 — 이전 선 / 이후 선 하나씩 끄고 보기

> 요청: "그리고 그래프에서 이전과이후 그래프 하나씩 끄기 켜기로 선택할 수
> 있어서 비교하기 더 쉽게 해줘"

## 왜 필요한가

두 선이 거의 같은 자리에 있으면 **뒤에 그려진 쪽이 앞의 쪽을 덮습니다.**
이전과 이후가 대부분 같은 로그에서는 그게 보통이고, 그러면 아래 둘을
구별할 수가 없습니다.

```
두 선이 완전히 같다            이후가 이전을 덮고 있다
   ───────────                   ───────────
```

[파형 분리 보기] 로 위아래로 벌려 볼 수는 있었지만, 그건 눈금을 비켜 그리는
것이라 값을 읽을 수가 없습니다.

## 어떻게

도구 줄에 **[선 보기] — [이전] [이후]** 를 뒀습니다.

```
선 보기  [이전] [이후]       ← 글자색이 그 선의 색입니다
```

**단추 글자색을 그 선의 색**(`Brush.Before` / `Brush.After`)으로 뒀습니다.
어느 쪽을 끄는 단추인지 글자를 읽지 않고도 압니다.

## 정한 것들

### 1. 끈 쪽은 세로 눈금 계산에서도 빠집니다

이게 핵심입니다. 안 보이는 선 때문에 눈금이 넓어지면 **보이는 쪽이
납작해져서 끈 보람이 없습니다.**

```csharp
if (ShownB && vm.InBefore && _state.Before != null) { ... }   // ChannelRange
if (ShownA && vm.InAfter  && _state.After  != null) { ... }
```

이전이 0~10 이고 이후가 0~1000 인 IO 에서 이후를 끄면, 눈금이 0~10 으로
좁혀져 이전의 잔 흔들림까지 보입니다. 끄기 전에는 바닥에 눌린 평평한 선이었던
것이 그렇게 드러납니다.

### 2. 한쪽만 켜 두면 벌리지 않습니다

```csharp
double sep = (_separate && haveB && haveA) ? inner.Height * 0.02 : 0.0;
```

[파형 분리 보기] 가 켜져 있어도, 벌릴 상대가 없는데 비켜 그리면 **그 선만
눈금에서 어긋나** 보입니다. 값을 잘못 읽게 됩니다.

[차이 영역 표시] 도 같은 이유로 저절로 빠집니다 — 칠할 두 선 중 하나가
없으니 `_shade && haveB && haveA` 가 거짓이 됩니다.

### 3. 범례도 따라갑니다

한쪽만 켜 두면 범례가 `이전만 보기` / `이후만 보기` 한 줄이 됩니다.
**없는 선을 설명하면 그게 어디 있는지 찾게 됩니다.**

### 4. 둘 다 끌 수 있습니다 — 다만 기억하지는 않습니다

끄지 못하게 막으면 "왜 안 꺼지지" 가 되고, 말없이 비워 두면 고장으로 보입니다.
그래서 **끌 수 있게 두고, 그래프에 그 사실을 적습니다.**

```
이전 선과 이후 선을 둘 다 꺼 두었습니다.
위 도구 줄의 [선 보기] 에서 하나를 켜 주세요.
```

다만 **설정 파일에 둘 다 꺼진 상태로 남지는 않습니다.** 다음에 켤 때 빈
그래프로 시작하면 그게 고장으로 보입니다 — 어제 끈 것을 오늘 기억하지
못합니다.

```csharp
if (!s.ShowBefore && !s.ShowAfter) { s.ShowBefore = true; s.ShowAfter = true; }
```

### 5. 차이 눈금에서는 꺼져 보입니다

`차이 (이후−이전)` 는 선이 하나뿐이고 **두 로그가 다 필요한 값**입니다.
한쪽만 끄는 것이 성립하지 않으므로 단추가 꺼져 보입니다
(`IsEnabled="{Binding ScaleRaw}"`). 눌리지도 않는데 켜 보이면 눌러 놓고
왜 안 바뀌나 하게 됩니다.

## 자체 테스트

**테스트 4 개를 더했습니다 (389 → 393).** 설정 파일 쪽입니다 —

- 둘 다 끈 파일은 둘 다 켠 것으로 읽히는지
- **한쪽만 끈 것은 그대로 사는지** (그게 쓰는 상태입니다)
- 옛 설정 파일(열쇠가 없음)은 둘 다 켠 것으로 보는지

### 아직 확인 못 한 것

- 단추 글자색이 테마를 따라가는지 (`DynamicResource` 로 걸었습니다)
- 차이 눈금에서 단추가 정말 꺼져 보이는지
- 도구 줄이 한 줄 더 늘었습니다. **3 줄 안에 들어가는지** 윈도우에서 봐
  주세요 — 넘치면 [선 보기] 를 [비교] 칸 안으로 합치겠습니다.
