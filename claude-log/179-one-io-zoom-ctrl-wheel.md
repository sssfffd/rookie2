# 179 — 1.87 IO 하나에서 확대한 것은 그 IO 에만 · Ctrl + 휠 = 모두 같이

## 요청 (요청 206)

> 그래프 하나 들어가서 확대하는 것도 전체 적용되던데 이거 하나만 적용되게 하고, 휠은 전체 적용 안 되는데 컨트롤 휠은 전체 되는 것도 다시 바꿔 주셈

## 원인

갤러리에서 칸을 두 번 눌러 IO 하나 (Lane, 줄 하나) 로 들어가면 줄이 하나뿐이라 "줄마다 구간" 이 꺼지고,
휠 · 끌기가 **공통 구간** 을 바꿨습니다. [◀ 갤러리로] 로 오면 그 공통 구간이 **모든 칸** 의 구간이라 전부 확대돼 있었습니다.
게다가 들어가고 나올 때 세로 배율을 모든 칸에서 지웠습니다.

## 한 것

| 무엇 | 어떻게 |
|---|---|
| 들어갈 때 | 갤러리 보기 (공통 구간 · 칸마다 구간 · 칸마다 세로) 를 통째로 적어 둠 (`GraphCanvas.TakeSnapshot`). IO 하나는 **그 칸이 보던 구간 · 세로** 로 시작 (`EnterOne`) |
| 뒤로 올 때 | 갤러리로 바꾸기 **전에** IO 하나의 보기를 적고 (보기를 바꾸면 세로가 지워져서), 갤러리 보기를 되살린 뒤 **그 IO 칸에만** 본 구간 · 세로를 얹음 (`LeaveOne`). 공통 구간 그대로 나왔으면 그 칸에 따로 구간을 두지 않음 |
| Ctrl + 휠 | **모든 그래프 같이** 확대 · 축소 (1.78 의 동작 — 칸마다 구간을 가진 줄도 같은 비율). 그래프 위면 고르지 않아도 됨. 단계로 나눠 보기면 모든 단계 칸 |
| 휠 | 그대로 — 고른 그래프만 (1.85), 고르지 않은 곳은 화면 굴리기 |

```
갤러리                IO 하나 (SPIKE)          ◀ 갤러리로
┌A┐┌SPIKE┐┌C┐   →    ┌ SPIKE ─────┐  휠 확대  →  ┌A┐┌SPIKE*┐┌C┐
└─┘└─────┘└─┘        └────────────┘              └─┘└──────┘└─┘
 0~100 공통             40~50                    A · C 는 0~100 그대로, SPIKE 만 40~50
```

파일: `Analysis1/Graph/GraphCanvas.cs` (`TakeSnapshot` · `EnterOne` · `LeaveOne` · `TryLaneTime`, `OnMouseWheel` Ctrl), `GraphView.xaml.cs`.
(같이: GraphView 의 문서 주석 순서가 1.86 에 꼬인 것 바로잡음.)
