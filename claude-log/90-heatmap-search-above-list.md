# 90 — 히트맵 검색 칸을 IO 목록 바로 위로 · 쓰는 법 글 빼기

> 그 히트맵에 io 검색 기능을 io리스트 바로 위에 적어주고
> 빨강 초록 이런 설명 외에 칸을 누르면 어쩌구 글자들 지워주셈

## 1. 검색 칸 자리

```
전 (1.07)                                      후 (1.10)
[히트맵 다시 계산] [검색____][검색 지우기] …     [히트맵 다시 계산] [가로를 단계로] …
요약 / 색 설명                                  요약 / 색 설명
차이가 난 IO 4개 │ 10:00 │ …                   IO 검색 [_______][✕]
▼ 온도      2개  │       │                     차이가 난 IO 4개 │ 10:00 │ …
                                                ▼ 온도      2개  │       │
```

- 도구 줄에서 빼서 **IO 이름 칸 바로 위**에 한 줄로 두었습니다. 그래프 화면처럼
  목록 바로 위에 있어야 "이 목록을 거른다" 로 읽힙니다.
- 폭은 판의 이름 칸(196)과 같게 맞췄습니다. `HeatmapCanvas.NameW` 를 바꾸면
  XAML 의 `Width="196"` 도 같이 바꿔야 한다고 주석에 적어 두었습니다.
- [검색 지우기] 는 자리가 좁아 `✕` 로 줄였습니다 (풍선말 "검색 지우기").
- 동작은 그대로입니다 (그래프 검색과 같은 규칙, 치는 대로 바로 걸러짐).

## 2. 쓰는 법 글 빼기

색 설명 줄 끝의 `칸을 누르면 그 IO 와 그 시간대로 그래프 화면이 열립니다. 그룹
이름 줄을 누르면 … Ctrl+휠 = 칸 너비, Shift+휠 = 옆으로` 를 뺐습니다. 남은 것은
색 설명 셋(차이 발생 · 정상 · 기록 없음)뿐입니다. 쓰는 법은 README 단축키 표에
그대로 있습니다.

## Windows 에서 확인 못 한 것

- XAML 은 여기서 컴파일되지 않습니다 (스텁 + 검사기만 통과).
- 검색 칸이 이름 칸과 딱 맞는 폭으로 보이는지 (DPI 배율에서도).
- 검사: 컴파일 · 테스트 859 통과 · `check_sources` / `check_handlers` /
  `check_shadowing` 지적 없음.
