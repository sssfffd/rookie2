# 199 — 발표 자료 1 장: 데이터 흐름 아키텍처 (아이콘 · 화살표)

## 요청 (요청 226)

> 아니 그 분석 3개가 화살표나 선으로 연결되서 어떻게 작동하나가 나와있어야해
> 막 그런거 있잖아 Log 아이콘 집어넣는 거 표시되어 있고 그다음에 이 데이터가 어디로 가고 그런느낌의 아키텍처

## 한 것

`docs/presentation/LogScope-아키텍처-기술.pptx` 1 장을 표 → **데이터 흐름 그림**으로 바꿈 (2 · 3 장 그대로).

```
분석 1  [Log][Log] → [로그 파서] → [판정 엔진] → [공정 일치율] ─┐
                                                   ┊ 같은 IO 짝   │      ┌→ [메인 화면]
분석 2  [DB] [DB]  → [덤프 파서] → [구조 비교] → [바뀐 값 N 개] ─┼→ [결과 취합] ┤
                                                                │      └→ [LLM 종합 분석] → [종합 분석 결과]
분석 3  [폴더][폴더] → [분석 3 모듈 (교체형)]   → [판정·유의점] ─┘
                         ↑ 설정 · config.txt (점선)
```

- 입력은 아이콘 (로그 문서 · DB 원통 · 폴더) 두 개씩 (이전 · 이후), 단계마다 아이콘 (파서 · 저울 · 막대 · 퍼즐 · 겹침 · 화면 · 로봇 · 보고서).
- 분석 1 판정 엔진 · 결과 취합 · 종합 분석 결과를 진하게. 주황 점선 = 분석 1 ↔ 2 같은 IO 짝.
- 아이콘은 이 작업 환경에서만 그림으로 만들어 넣음 (react-icons → PNG). 프로그램에는 들어가지 않음.
