## 한 것 (코드 변경 없음 — 시안 먼저)

WPF 화면은 여기서 띄워 볼 수 없어, 고치기 전에 **브라우저로 보는 시안**을 만들었습니다 (예시 데이터):
https://claude.ai/artifact/AJ9gPvKqvf4WFKFp7bDhAS (밝게 / 어둡게 전환 — Tweaks)

| 참고한 것 | 시안에 쓴 것 | 우리 데이터 |
|---|---|---|
| Grafana 스탯 패널 · 게이지 | 맨 위 한 줄: 최종 판정 (큰 칸) · 점수 게이지 (90 / 70 경계 색) · 차이 IO · 평균 오차율 (크기 반영) · 로그 길이 · 분석 2 · 분석 3 | OverallVm · JudgeScore · 칸 VM |
| Splunk 타임라인 | **시간대별 차이** 막대 (이전 로그 100 칸, 높이 = 그 칸 차이 IO 수, 색 = 100 % 넘게 벌어진 칸) | JudgeScore 의 100 칸 (칸별로 모으기만 더하면 됨) |
| EAP 레시피 단계 · 장비 상태 타일 | 막대 아래 **공정 단계 띠**, 오른쪽 **그룹 상태 타일** (차이 IO / 전체, 색) | 단계 (StepPairList) · 그룹 |
| WhaTap Top-N | **차이 큰 IO** 표 — 판정 배지 · 오차율 막대 (진한 = 시간, 옅은 = 크기 반영) · 최대 차이 (+340 %) · 언제 | JudgeScore.Rates / WeightedRates · 판정 오차 |
