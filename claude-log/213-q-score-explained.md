# 213 — (질문) 종합 판정 점수 · 공정 일치율 셈 (2.08 기준)

## 요청 (요청 240)

> 지금 종합 판정 점수랑 일치율 점수 어떻게 계산되는지 말해줘

## 답

### 공정 일치율 (분석 1)
1. 이전 로그 시간을 100 칸으로 나눔.
2. IO 마다 허용 안 된 오차가 걸친 칸에 무게 = 1 + 허용 오차를 넘은 % / 50 (최대 3).
3. 크기 반영 오차율 = 무게 합 (최대 100 %). 한쪽 로그에만 있는 IO 는 100 %.
4. IO 일치도: 정상 (차이 없음 · 허용) 1, 차이 IO 0.5 × (1 − 크기 반영 오차율 / 100).
5. 공정 시간 일치율 = 1 − 허용 안 된 "로그 길이" 오차 비율.
6. **공정 일치율 = 100 × Σ IO 일치도 / 전체 IO × 공정 시간 일치율** → 95 정상 · 80 주의 · 그 아래 이상.

### 종합 판정 (최종)
1. 분석별 점수: 분석 1 = 공정 일치율, 분석 2 · 3 = 판정 구간 가운데 (정상 97.5 · 주의 87.5 · 이상 40).
2. 종합 점수 = 54 · 30 · 16 가중 평균 (결과가 있는 분석만, 남은 가중치로 다시 나눔).
3. 95 정상 · 80 주의 · 그 아래 이상. 정상 · 주의면 낱말 옆에 점수.
4. 넉아웃: 분석 1 이상 → 최종 이상, 다른 분석 이상 → 적어도 주의.

(질문이라 버전은 그대로 2.08.)
