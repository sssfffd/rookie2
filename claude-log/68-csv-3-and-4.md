# 68 — v1·v2 와 표를 걷어내고 `.csv` 의 3·4 로 견주기 (0.87)

## 주신 말

> csv파일의 경우 1,2,3,4,5,6으로 형식이 되있고 첫째줄엔 항목 명
> 2줄부텨 데이터가 들어있거든?
>
> 일단 원래 코드에 v1,v2관련 내용이랑 기능들 지우고
> 표라고 따로 분리하는 거 지우고
> 3과 4를 집어넣어서 비교하는 걸로 해주셈

"3과 4" 가 **3번=IO 이름(열쇠), 4번=값** 이라고 확인하고 넣었습니다.

## 3) `.csv` 는 3 번 열쇠 · 4 번 값

```
1,2,3,4,5,6         ← 첫 줄은 열 이름
…,…,IO 이름,값,…,…   ← 둘째 줄부터 자료
```

**3 번 열로 행을 짝짓고 4 번 값을 견줍니다.** 나머지 열은 읽지 않습니다 —
읽어 두면 "안 본 열인데 왜 차이에 안 나오지" 가 되고, 견주면 묻지 않은
차이가 쏟아집니다.

자리는 `DbNames.cs` **두 줄**입니다 (`CsvKeyColumn` · `CsvValueColumn`).

### 이게 큰 것을 하나 고칩니다

전에는 `.csv` 에 열쇠가 없어서 **값이 하나 바뀐 행이 "없어진 행 + 생긴
행"** 으로 보였습니다. 그래서 0.82 의 빨간 줄과 `차이 발생 : N개` 가
CSV 에서는 거의 안 잡혔습니다. 이제 잡힙니다.

### 안 본 열은 화면에 적습니다

```
old_2026-03-14.csv — 6 개 열 중 3 번(io)으로 행을 짝짓고 4 번(value) 값을
견줍니다. 안 본 열: no · addr · unit · note
```

처음엔 이 말이 표 안에만 있고 **화면까지 안 갔습니다.** 그러면 안 본 열이
있다는 것을 모르고 "차이가 없네" 로 읽게 됩니다 — 올리는 길을
만들었습니다 (같은 모양의 파일이 여럿이면 한 번만 적습니다).

열이 4 개가 안 되는 파일은 **짐작하지 않고** 통째로 읽은 뒤 그렇다고
적습니다.

## 끝에서 끝까지 돌려 봤습니다

실제 모양의 `.csv` 두 장으로 (이름도 다르게) 돌린 결과입니다.

```
차이 발생 : 1개      없어진 IO : 1개      새로 생긴 IO : 1개

알림: 이전: old_2026-03-14.csv — 6 개 열 중 3 번(io)으로 행을 짝짓고
      4 번(value) 값을 견줍니다. 안 본 열: no · addr · unit · note
알림: 이름이 다른 파일을 짝지었습니다: 'old_2026-03-14' ↔ 'new_2026-03-21'

IO명        이전      이후      색
TEMP_MAX    180       185       빨강
PRE_HEAT    ON
COOL_TIME             30
```

`FLOW_SET` 은 안 보는 열(note)만 달라져서 목록에 없습니다. 맞는 동작입니다.

### 돌려 보다 진짜 버그 둘을 잡았습니다

**(가) `ON` 이 `TRUE` 로 바뀌어 있었습니다.**

`.csv` 읽기가 로그용 읽기를 그대로 쓰는데, 그쪽은 글자를 보고 참거짓과
숫자를 **가립니다** (그래야 그래프를 그립니다). 그래서 `ON` → 참 →
화면에 `TRUE`, `12.0` → 12 → `12` 로 적혔습니다.

견주는 도구에서 이건 **차이를 숨깁니다.** 한쪽이 `ON`, 다른 쪽이 `1` 이면
둘 다 참이 되어 **같은 값으로 보입니다.** 읽는 쪽에 "적힌 글자 그대로"
모드를 넣고 DB 쪽이 그걸 쓰게 했습니다.

**(나) 없어진 행 하나가 줄 둘로 나왔습니다.**

```
PRE_HEAT   PRE_HEAT      ← 열쇠 열(io)
PRE_HEAT   ON            ← 값 열(value)
```

열쇠 열의 값은 **이미 IO명 칸에 있습니다.** 열쇠가 한 열이면 그 열은
줄로 적지 않게 했습니다.

**둘 다 시험만으로는 안 나왔을 것들입니다.** 실제 모양으로 한 번
돌려 본 것이 잡았습니다.

## 덤: IO명 칸이 `io=TEMP_MAX` 였습니다

열쇠가 **한 열**이면 그 값만 적습니다 (`TEMP_MAX`). 행을 가리키는
글(`io=TEMP_MAX`)은 `행` 칸에 그대로 있습니다.
