# 134 — LLM 서버 연결 확인 · 안 되면 분석 3 · 종합 분석 결과 막기

> 이게 llm서버에 저걸 보내잖아 / 근데 llm이 불가능한 환경일 수도 있거든? / 그래서 설정에서 llm 서버 ip 적고
> 연결 확인누르면 서버에 핑이나 뭔갈 보내서 통신이 가능해야지 분석 3과 종합 분석이 사용 가능하게 해줘 /
> 프로그램 시작했을때도 지금 되어있는 ip기준으로 자동으로 한번 연결확인 돌려야지 / 연결 안되어있으면 이제
> 분석 3이랑 종합분석 결과 회색 반투명으로 비활성화 표시 해주고 LLM 서버와 접속이 불가능한 환경입니다.
> 설정에서 IP 주소 혹은 서버의 상태를 확인하여주시기 바랍니다. 라고 안내문구도 적어주셈

## 바꾼 것 (1.51)

**설정 → "LLM 서버" 탭** — 서버 주소 칸 · [연결 확인] · 상태 줄(● 연결됨 / 연결 안 됨 / 확인 중 + 까닭).

| 주소 모양 | 확인 방법 |
|---|---|
| `10.0.0.5` | 핑 (ICMP) — 그 PC 가 살아 있는지만 |
| `10.0.0.5:8000` (권장) | 그 포트로 TCP 접속 — 서버 프로그램이 떠 있는지까지 |
| `http://10.0.0.5:8000/v1` | 주소의 호스트 · 포트(없으면 80/443)로 TCP 접속 |

데이터는 보내지 않고 닿는지만 봅니다 (3 초 한도). 주소는 설정 파일(`llmServer`)에 저장. 인증 정보는 적지 않음.

**언제 확인하나**: 프로그램을 켤 때 한 번(지금 주소로, 뒤에서) · [연결 확인] · 설정 창을 닫았는데 주소가 바뀌었을 때.

**안 닿으면** (확인 중 · 주소 없음 포함) 세 곳을 회색 반투명으로 덮고 누름도 막습니다:

```
┌ 종합 분석 결과 ─────────────────────── [LLM 분석 실행] ┐   ← 덮개 아래는 꺼짐
│░░░░░░░┌──────────────────────────────────────┐░░░░░░░│
│░░░░░░░│ LLM 서버와 접속이 불가능한 환경입니다.│░░░░░░░│
│░░░░░░░│ 설정에서 IP 주소 혹은 서버의 상태를    │░░░░░░░│
│░░░░░░░│ 확인하여주시기 바랍니다.               │░░░░░░░│
│░░░░░░░│ 10.0.0.5:8000 — 3 초 안에 응답 없음    │░░░░░░░│   ← 무엇을 확인했고 왜 안 됐는지
│░░░░░░░└──────────────────────────────────────┘░░░░░░░│
```
1. 메인 **종합 분석 결과** 칸 (버튼도 꺼짐)
2. 메인 **분석 3 칸** (이전/이후 · [분석] · 요약)
3. **분석 3 화면** (사용자 화면 위)

확인 중에는 "LLM 서버 연결을 확인하는 중입니다…".

| 파일 | |
|---|---|
| `Common/LlmServer.cs` (새) | 상태 · `CheckAsync` (배경 스레드, 마지막 확인만 씀) · `Probe` (핑 / TCP) · `TryParse` · 덮는 글 |
| `Settings/AppSettings.cs` · `SettingsVm` · `SettingsWindow` · `SettingsTexts` | 주소 · 탭 · [연결 확인] · 상태 줄 |
| `Common/CommonTexts.cs` | `LlmBlocked` (요청 문구 그대로) · `LlmChecking` |
| `Main/MainVm` · `LlmPanelVm` · `AnalysisCardVm` · `MainView.xaml` | `RefreshLlmServer` · 덮개 · 버튼 끔 |
| `Shell/ShellVm` · `ShellWindow` | 분석 3 화면 덮개 · 켤 때 확인 · 설정 뒤 다시 확인 |
