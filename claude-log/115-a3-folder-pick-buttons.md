# 115 — 분석 3 칸: 폴더 고르기 + [분석] · [리포트] 단추

> 분석 3 쪽에서 이전 이후 클릭했을 때 파일만 선택하던데 폴더 선택으로 바꿔주고
> 분석 및 리포트 버튼 넣어주셈 버튼이랑 기능 연결은 내가 할게

## 바꾼 것 (1.35)

| | 전 | 후 |
|---|---|---|
| 분석 3 칸 이전/이후 누름 | 파일 고르는 창 | **폴더 고르는 창** (`FolderBrowserDialog` — 설정 창과 같은 .NET Framework 기본 것). 끌어다 놓기는 파일 · 폴더 다 됨 |
| 빈 칸 글 | "누르면 파일 고르기 · 폴더는 끌어다 놓기" | "누르면 폴더 고르기 · 끌어다 놓기" (`MainTexts.A3NoneOnCard`) |
| 단추 | — | 칸 머리에 **[분석] [리포트]** (`MainTexts.A3Analyze` · `A3Report`) |

```
┌ 분석 3 ─ 이름 ────────── [분석] [리포트] ↗ ┐
│ [FAIL]  차이 발생 [2] 개                   │
│ ● 이전  before_dir                  폴더   │
│ ● 이후  after_dir                   폴더   │
│ ┌ 요약 ────────────────────────────────┐   │
```

**머리 줄에 둔 까닭**: 칸 셋의 이전/이후 · 요약 줄이 나란히 놓여야 합니다. 칸 안에 줄을 더 두면
분석 3 칸만 아래로 밀립니다. 단추 높이를 화살표와 같은 26 으로 맞춰 머리 줄 높이도 그대로.

**연결**: 단추는 메인 화면(Analysis3 밖)에 있어서 사용자가 직접 고치면 새 버전에 덮입니다. 그래서
누르면 `Analysis3Link.AnalyzeRequested` / `ReportRequested` 가 울리고, 사용자가 Analysis3 쪽에서 연결합니다.

```csharp
Analysis3Link.AnalyzeRequested += (s, e) => OnRunClick(null, null);
Analysis3Link.ReportRequested += (s, e) => MakeReport();
```

연결이 없으면 "분석 3 쪽에 이 단추와 연결된 기능이 아직 없습니다" 와 연결할 이벤트 이름을 알림.
