# 55. "사람이 보기 힘들다" — 재 보고 고친 것 (0.74)

> 너가 짠 코드 수정할려니까 너무 사람이 보기 힘들게 한 것 같은데?

짐작으로 답하지 않고 재 봤습니다. **네 가지가 나왔고 그중 둘은 분명히 제
잘못입니다.**

## 재 본 것

| 무엇 | 숫자 |
|---|---|
| 60 줄 넘는 함수 | **16 개** (가장 긴 것 122 줄) |
| 12 줄 넘게 이어지는 주석 덩이 | **48 곳** (가장 긴 것 30 줄) |
| 일반 주석(`//`)에 들어간 `<b>` · `<c>` 태그 | **31 줄** |
| 1000 줄 넘는 파일 | 5 개 (테스트 3252, GraphCanvas 2005, DbRead 1105 …) |

## 고친 것 (0.74)

### 1. `<b>` · `<c>` 태그를 일반 주석에서 뗐습니다 (31 줄)

이건 그냥 제 실수입니다. `<b>` 는 `///` 문서 주석에서 Visual Studio 가
굵게 보여 주는 표시입니다. **`//` 주석에서는 아무 뜻이 없고 글자만
지저분해집니다.**

```
전   // .frm 은 <b>나중에</b> 읽습니다.
지금 // .frm 은 나중에 읽습니다.
```

### 2. 110 줄짜리 `DbRead.Read` 를 네 걸음으로 쪼갰습니다

고치시겠다는 그 파일의 입구이고, 한 함수가 다섯 가지 일을 하고 있었습니다.
"어느 파일을 읽을지 고치려면" 110 줄을 다 읽어야 자기 자리를 찾았습니다.

```csharp
Files(...)       // 1. 훑어서 목록 만들기 (하위 폴더까지)
ReadTables(...)  // 2. .sql / .csv 읽기   ← 새 확장자를 더하는 자리
ReadFrm(...)     // 3. .frm 읽기 (2 보다 나중인 이유는 그 함수 머리에)
Notes(...)       // 4. 무엇을 읽고 못 읽었는지 적기
```

입구는 20 줄로 줄었고, 걸음마다 이름이 무엇을 하는지 말해 줍니다. 세어 두는
값들은 `Seen` 한 곳에 모았습니다 — 전에는 지역 변수 아홉 개가 함수 중간에
흩어져 있었습니다.

**옮기기만 했습니다.** 테스트 **630 통과 / 0 실패**, 옮기기 전과 같은 수입니다.

## 남은 둘 — 이건 제가 정하면 안 되는 자리입니다

### 3. 주석 덩이 48 곳

제일 큰 덩어리입니다. 함수 하나 고치려고 열면 **왜 그렇게 했는지 설명이
먼저 20~30 줄** 나옵니다.

이렇게 쓴 이유는 처음 주신 요구였습니다 — "위험해 보이는 부분을 설명해줘".
그래서 "이걸 이렇게 바꾸면 이런 게 깨진다" 를 코드 옆에 붙여 뒀습니다.
0.42 의 `ClearValue`, 0.59 의 되돌릴 배경처럼, **그 설명이 없었으면 다음에
같은 고장을 또 냈을** 자리들입니다.

고르실 수 있습니다.

| 길 | 어떻게 | 잃는 것 |
|---|---|---|
| **A. 그대로** | — | 지금 불편함 |
| **B. 두세 줄로 줄이고 자세한 건 claude-log 로** | 주석에 `(까닭: claude-log/35)` 한 줄만 남김 | 코드만 보는 사람은 까닭을 못 봄 |
| **C. 짧은 "건드리지 마시오" 만 남김** | 한 줄 경고 + 나머지 삭제 | 왜 안 되는지 모름 |

**B 를 권합니다.** 폰으로 요청 넣고 PC 에서 git 으로 보신다고 하셔서
claude-log 를 쌓아 왔는데, 그게 이미 까닭을 담는 자리입니다. 코드 옆에는
"조심할 것" 만 두면 됩니다.

### 4. 긴 파일

| 파일 | 줄 | 어떻게 |
|---|---|---|
| `LogScope.Tests/Program.cs` | 3252 | 갈래별로 쪼갤 수 있습니다 (로그 · DB · 설정 …) |
| `Controls/GraphCanvas.cs` | 2005 | 그리기 · 입력 · 눈금으로 쪼갤 수 있습니다 |
| `Db/DbRead.cs` | 1105 | **0.73 에 제가 합친 것**입니다 |

마지막 줄이 걸립니다. 0.73 에 "참고할 파일이 너무 많다" 고 하셔서 열 개를
다섯 개로 합쳤는데, **파일 수를 줄이면 파일이 커집니다.** 둘을 같이 줄이는
방법은 없고, 어느 쪽이 덜 불편한지만 고를 수 있습니다.

지금 모습(다섯 파일 · 각 900~1100 줄)이 불편하시면 **일곱 개쯤으로** 다시
나누는 것이 중간입니다 — 읽기를 `.sql`/`.csv` 와 폴더 훑기로 가르면
각각 600 줄 안쪽이 됩니다.
