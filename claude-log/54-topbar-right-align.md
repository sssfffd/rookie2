# 54. 그 화면 메뉴가 창 끝으로 밀려 있던 것 (0.72)

> 이거 센서값 변화량 분석 페이지 넘어갔을때 대시보드 같은 버튼 뜨는거
> 왤케 오른쪽으로 가있음?

## 제가 0.70 에서 낸 것입니다

위 줄을 한 줄로 다시 짜면서 오른쪽 묶음에 한 마디를 더했습니다.

```xml
<WrapPanel Grid.Column="2" HorizontalAlignment="Right" ...>
                           ↑ 이게 0.70 에서 들어갔습니다
```

그 전에는 없었습니다. 없으면 그 묶음은 남는 폭을 다 받되 **내용은 왼쪽에서
시작**합니다 — 구분 선 바로 뒤입니다.

```
0.70        LogScope  [메인][…][…][…] │                      [대시보드][그래프]… [설정]
0.72 (지금)  LogScope  [메인][…][…][…] │ [대시보드][그래프]… [설정]
```

## 왜 붙여야 하나

구분 선은 **"여기부터 다른 갈래"** 라는 표시입니다. 0.45 에서 "화면 전환은
왼쪽, 원래 메뉴는 오른쪽, 칸 구분되게" 로 만든 그 선입니다. 선 뒤에 바로
붙어 있어야 그 뜻이 살아납니다 — 창 끝으로 밀어 놓으면 선과 메뉴 사이가
통째로 비어서, 선이 무엇을 가르는 표시인지 알 수 없습니다.

그리고 **손이 멉니다.** 넓은 화면에서 `[분석 1]` 을 누르고 바로
`[대시보드]` 를 누르려면 창 끝까지 손을 옮겨야 합니다. 이어서 누르는 두
단추는 가까이 있어야 합니다.

## 왜 그렇게 넣었나

0.70 에서 칸을 둘에서 셋으로 늘렸습니다 (이름 칸 · 화면 단추 · 그 화면
메뉴). 마지막 칸이 남는 폭을 다 받게 되니 "그럼 오른쪽에 붙여야지" 하고
한 마디를 더했습니다. **묻지 않고 더한 것**이고, 원래 모양을 바꾼 것인데
그걸 적어 두지도 않았습니다.

고치면서 그 자리에 **왜 붙이지 않는지**를 주석으로 적어 뒀습니다. 다음에
칸 수를 또 바꿀 때 같은 한 마디를 또 더하지 않도록.

## 가는 길에 바로잡은 것

처음에 "0.69 에서 들어갔다" 고 말씀드렸는데 `git log -S` 로 보니 **0.70**
이었습니다. 바로 지난 판입니다.

테스트 **630 통과 / 0 실패**, 검사 넷 다 통과.

**못 해 본 것**: 화면 모양입니다. 구분 선과 `[대시보드]` 사이 간격이
너무 붙었거나 벌었으면 그 선의 `Margin="14,4,4,4"` 숫자만 고치면 됩니다.
