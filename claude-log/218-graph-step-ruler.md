# 218 — 2.12 단계 띠: 단계 IO 만 넣으면 전체 그래프 맨 위에 1 · 2 · 3

## 요청 (요청 245)

> 아니 지금은 단계마다를 클릭안하면 이게 단계표시가 안보이잖아 비교의 단계 IO에 입력하면 그래프에서 단계들이 보이게 띠를 만들어 달라는거임

## 원인

2.11 의 띠는 `_state.HasSteps` (두 로그에 **같은 단계가 짝지어진** 것이 있을 때) 일 때만 나왔고, 줄마다 머리 아래 15 px 라 눈에 잘 안 띄었습니다.
단계 IO 를 넣어도 이후 로그 쪽 단계가 안 맞으면 띠가 없었습니다.

## 고친 것

    [단계마다] 꺼짐 (전체 그래프)
    단계 │ 1  준비 │        2  가열           │ 3  유지 │   ← 맨 위 한 줄 (칸 머리 줄과 같은 높이 22 px)
    ─────┼─────────┼──────────────────────────┼─────────┤
    AI_T │  ╱      ┆   ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾  ┆  ╲_     │   ← 줄마다 단계 경계 점선
    AI_P │ ___     ┆      ╱‾‾‾‾‾‾‾╲           ┆         │

- 조건: 나눠 보지 않고, 가로축 기준 로그 (이전, 없으면 이후) 에 단계가 있으면 — 단계 IO 만 적으면 됨 (짝지음 불필요).
- 칸: 단계 시작 → 다음 단계 시작까지, 두 색 번갈아 (강조색 옅게), "번호  이름" → 좁으면 번호 → 더 좁으면 비움.
- 줄 · 겹쳐보기: 맨 위 한 줄. 갤러리: 칸마다 머리 아래 작은 띠 (칸이 가로 3 개라 맨 위 한 줄로는 자리가 안 맞음).
- 단계 경계 점선은 줄마다 그 줄의 시간 자리 (줄만 확대해도 맞음).
- 나눠 볼 때는 칸 머리 줄이 같은 일 (그대로).
- 파일: `Analysis1/Graph/GraphCanvas.cs` (MarkSteps · ShowStepRuler · DrawStepStrip · DrawStepBounds), `scripts/wpfstub/WpfStubs2.cs` (DashStyle 시험용 대역), README.
