# 116 — 메인 화면 분석 3 칸의 결과 자리 비워 두기

> 아 그리고 메인화면에 분석 3 결과로 막 리포트나 시간대 뜨는거 일단 비워놓아 주셈

분석 3 쪽이 `Analysis3Link.Publish` 로 올린 결과(리포트 · 시간대 같은 줄)가 메인 칸 요약에 뜨던 것을
**당분간 비워 둡니다** (1.36).

| | 상태 |
|---|---|
| 낱말 · 점수 · "차이 발생 N 개" · 요약 줄 | 비움 (`Publish` 해도 안 적음) |
| 요약 칸 안내 글 | 비움 — 분석 3 은 그룹 이야기("그룹이 없거나…")도 안 적음 |
| 이전 · 이후 자리, [분석] [리포트], 탭 이동 | 그대로 |
| `Analysis3Link.Result` | 그대로 쌓임 (분석 3 쪽 코드는 고칠 것 없음) |

다시 보이려면 `src/LogScope/Main/MainVm.cs` 의 `public static readonly bool A3ResultOnCard = false;` 를
`true` 로 바꾸고 빌드.

확인: 리눅스 컴파일 · 시험 911 통과, 실제 C# 7.3 컴파일러 오류 0. 화면 모양은 Windows 에서 확인 필요.
