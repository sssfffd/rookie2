# 194 — 1.98 맨 위 분석 3 칸도 "결과 없음"

## 요청 (요청 221)

> 최상단에 분석3 결과 없음으로 만들라니까

## 까닭

분석 3 이 LLM 서버에 닿지 않으면 칸이 "못 씀" 상태가 되고, 맨 위 대시보드 칸은 그때 **"못 씀"** 을 적었습니다
(1.92 규칙). 1.95 · 1.97 에서 "결과 없음" 으로 바꾼 것은 결과가 없을 때뿐이라 이 경우가 남았습니다.

## 한 것

- `AnalysisCardVm.LampWord` = `WordOf(LampGrade)` — 못 쓸 때도 "결과 없음" (글꼴도 왼쪽 칸들과 같은 16 · 보통 · 흐림, 그림 없음).
- `LampIcon` 글자도 같은 규칙 ("–" 없앰).
- 최종 판정은 예전처럼 분석 3 을 무시 (결과 없음과 같은 취급). 못 쓰는 까닭은 아래 분석 3 칸에 그대로.

```
[분석 2     ]  [분석 3     ]
[● 정상     ]  [결과 없음  ]   ← 예전: "– 못 씀"
```

## 확인

- 시험 1122 통과 ("분석 3 을 못 쓰면 무시 · 맨 위 칸도 '결과 없음'").
- **Windows 에서 못 본 것**: 실제 LLM 서버가 없는 상태의 화면.
