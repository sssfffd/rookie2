# 177 — 1.85 휠은 고른 그래프만 확대 · 축소

## 요청 (요청 204)

> 그래프에서 휠 돌리는 거 한꺼번에 다 되게 하지 말고 선택된 창만 확대 · 축소되게 해 주셈

## 한 것

1.83 에서 "고른 그래프 위에서만 휠 확대" 로 했지만 확대 자체는 1.78 의 **모든 줄 같이** 였습니다. 이제 **고른 그래프 하나만**.

| 화면 | 휠 (고른 그래프 위) |
|---|---|
| Lane (줄 여럿) · 갤러리 | **그 줄 · 그 칸만** — 그 줄이 자기 구간을 가짐 ("이 줄만 a ~ b", 끌기 · 오른쪽 네모와 같은 구조 `_laneTimes`). 다른 줄은 그대로 |
| 겹쳐보기 · 줄 하나 | 그래프가 하나뿐이라 그 판 전체 |
| 단계로 나눠 보기 | 예전처럼 커서 아래 단계 칸만 |
| Shift + 휠 (값) | 예전처럼 그 줄만 |
| 고르지 않은 곳 | 화면 굴리기 (1.83 그대로) |

모든 줄을 같이 바꾸는 길은 남겨 둠: `Time Scale` [+] [−], `+` `-` `←` `→`, `Home` (모두 같은 구간으로 되돌림).

```
 휠 ↻ (고른 IO_B 위)
 ┌ IO_A ─────────────┐   그대로
 ╔ IO_B ═════════════╗   ← 이 줄만 확대 · "이 줄만 a ~ b"
 └ IO_C ─────────────┘   그대로
```

파일: `Analysis1/Graph/GraphCanvas.cs` (`OnMouseWheel`).

## 확인

- 시험 1139 통과 (그림판 마우스 동작은 시험 밖), check 스크립트 · 실제 csc 빌드 통과.
- **Windows 에서 못 본 것**: Lane · 갤러리에서 휠로 고른 줄만 바뀌는지, "이 줄만 a ~ b" 표시, Home 으로 다 같이 돌아오는지.
