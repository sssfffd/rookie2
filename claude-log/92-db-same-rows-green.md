# 92 — 분석 2 [전체] 에서 차이 없는 줄은 초록

> 그리고 분석2에서 모든 거 볼때 차이 안난건 초록색으로 칠해주고

## 바뀐 것

```
보기 [차이 발생][전체]   ■ 값이 달라진 줄  ■ 차이 없는 줄   ← 초록 설명은 [전체] 일 때만

IO명        이전 value   이후 value
TEMP_MAX    1            4  (+3)       ← 옅은 빨강 (전과 같음)
PRES_SET    2.5          2.5           ← 옅은 초록 (새로)
```

- **[전체]** 로 볼 때만 들어오는 "두 쪽이 같은 줄" 을 옅은 초록으로 칠합니다.
  [차이 발생] 에는 그런 줄이 없어서 초록이 안 보입니다.
- 생김 · 없어짐 · 열 차이 줄은 전처럼 칠하지 않습니다.
- 색: 밝은 테마 `#E3F4E6`, 어두운 테마 `#233F2B` (`Brush.GoodSoft`, 옅은 빨강
  `Brush.BadSoft` 와 짝).

### `Mark` 가 아니라 `Change` 로 칠한 까닭

빨강은 `DbDiffLine.Mark` 로 칠합니다. 그런데 `Mark` 가 비어 있지 않은 줄은
`DbDiffList.Count` 가 **"차이 발생"** 으로 셉니다. 같은 줄에 `Mark` 를 붙이면
[전체] 로 볼 때 메인 화면 차이 개수가 늘어납니다. 그래서 `Change == 같음` 을 보고
화면(XAML)에서만 칠합니다 — 세는 쪽은 그대로입니다.

## Windows 에서 확인 못 한 것

- XAML 은 여기서 컴파일되지 않습니다 (스텁 + 검사기만 통과).
- 고른 줄 · 마우스 올린 줄 표시가 초록보다 앞서는지 (빨강과 같은 방식이라
  그럴 것으로 봅니다).
- 검사: 컴파일 · 테스트 859 통과 · `check_sources` / `check_handlers` /
  `check_shadowing` 지적 없음.
