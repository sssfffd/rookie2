# 214 — (질문) 횡전개

## 요청 (요청 241)

> 너 횡전개 알아?

## 답

횡전개 (橫展開, 수평 전개 · Yokoten) — 한 곳 (설비 · 라인 · 제품 · 공장) 에서 찾은 문제의 원인 · 대책 · 개선 사례를
**같은 구조를 가진 다른 곳에도 똑같이 적용**하는 일. 제조 현장 (품질 · 설비 · 공정) 에서 흔히 씀.

순서: 문제 · 개선 발견 → 원인 · 대책 확정 → 같은 조건의 대상 찾기 → 적용 → 적용 결과 확인 (효과 · 부작용).

LogScope 와 이어지는 자리: 횡전개 뒤 "적용 전 (이전) · 적용 후 (이후)" 로그 · DB 를 견줘 의도한 것만 바뀌었는지,
대상 설비마다 같은 판정 기준 (공정 일치율 · 설정값 비교) 으로 확인.

(질문이라 버전은 그대로 2.08.)
