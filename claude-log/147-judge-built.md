## 규칙
| 오차 | 판정 |
|---|---|
| 값 오차 (시간 여유 띠 밖), IO · 단계 안 비율 < 20 % | WARNING |
| 값 오차 ≥ 20 % | FAIL |
| 단계 길이 차이 > 시간 여유 · IO 한쪽에만 | WARNING |
| 단계 없어짐 · 생김 · 차례 바뀜 | FAIL (이번만 허용 가능) |

시간 여유 = 단계 길이 2 % (표본 간격 × 2 ~ 5 초). 모든 표본 · 양쪽에서 봄.
