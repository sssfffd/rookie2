# 172 — 축소해서 넓게 볼 때 두 선이 얇아 안 갈리던 것 (1.80)

> 그리고 그래프 구분하는게 확대하면은 괜찮아
> 근데 축소해서 작게 볼때는 구분이 거의 안되네
> 너무 얇게 나와

## 까닭
넓게 보면 표본이 픽셀보다 촘촘해서 열마다 위아래 끝을 잇는 선으로 그립니다. 이때 이전 (파랑 2.4 px) 이 이후
(빨강 1.4 px) 밑에서 양옆으로 0.5 px 씩만 비쳐, 안티에일리어싱에 묻혀 거의 안 보였습니다.

## 고침 — 넓게 볼 때 (표본 > 픽셀) 만

| | 확대 (표본 < 픽셀) | 넓게 (표본 > 픽셀) |
|---|---|---|
| 이후 (빨강) | 1.4 px | **1.8 px** |
| 이전 (파랑, 둘 다 그릴 때) | 2.4 px | **3.8 px** — 빨강 양옆 1 px 씩 |
| 한 선만 · 차이 선 | 1.4 px | **1.8 px** |

확대했을 때는 그대로 (괜찮다고 해서). 갤러리 칸처럼 작은 그림은 넓게 보는 경우가 많아 같이 굵어집니다.

## 확인
- 테스트 1129 통과, 실제 csc 7.3 오류 0, 검사 스크립트 통과
- **Windows 에서 못 봄** (선 굵기는 화면에서만)
