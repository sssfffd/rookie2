# 167 — 그래프 선이 왼쪽 기준선을 넘어 그어지던 것 (1.76)

> 이젠 문제가 그거임 그래프 화면을 넘어서까지 선이 그어지네
> 지금 보이는게 왼쪽 기준선을 넘어감

## 까닭
1.75 에 위 · 아래는 끝에서 자르게 했지만 **왼쪽 · 오른쪽은 안 잘랐습니다.**
- 끝에서 선이 안 끊기게 화면 바로 바깥 표본까지 이어 그림
- 고정 시간 격자 (1.75) 의 첫 열은 왼쪽 끝보다 (1 픽셀 안쪽만큼) 앞에서 시작

그림 칸을 자르는 것이 그래프 전체 폭 (값 눈금 자리까지) 이라, 선 · 차이 영역이 왼쪽 기준선을 넘어 값 눈금 쪽까지 그어졌습니다.

```
 값 눈금 │ 그림 칸
    100 ─┼──────────
      ╲  │╲          ← 넘어간 선 (이제 기준선에서 잘림)
     50 ─┼─╲─────────
```

## 고침
- 줄마다 선 · 차이 영역 칠하기를 **그림 칸 (기준선 안쪽)** 으로 자름 — 가로는 딱 맞게, 세로는 선 굵기만큼 (1 px) 여유
- 단계로 나눠 보기는 원래 칸마다 잘라서 그대로

- **Windows 에서 못 봄**: 실제 그림 (그림은 여기서 못 그림)
