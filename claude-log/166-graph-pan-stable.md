# 166 — 그래프를 확대 · 이동하면 파형 · 차이 영역이 달라지던 것 (1.75)

> 아 그리고 지금 차이 영역 나타낼 때 깨지는 부분이 있어 그래프 움직이면 기존하고 달라져버림
> 이 문제 원인일수도 있는데 그래프를 확대하면 최대최소 넘어가는 부분은 그냥 상한 하한선에서 일자로 그어진단 말임?
> 근데 그거 맞출려고 그래프 파형이 달라져버려
> 확대하면서 화면 움직이면 너무 달라짐 이건 고쳐야해

## 까닭 둘

**① 화면 밖 점을 위 · 아래 끝에 붙여 그림 (Clamp)**

```
 값 눈금 위끝 ─────────────●━━━━━━━━━━●      ← 붙인 점 (실제 값은 훨씬 위)
                         ╱                 
                        ╱  ← 실제로는 여기서 위끝을 지나 나가야 함
             ●─────────●                   
```
안에서 밖으로 나가는 선이 끝을 지나는 자리가 아니라 **다음 표본 자리까지** 비스듬히 그어져 보이는 파형의 기울기가 바뀌고,
끝선을 따라 가로줄이 생겼습니다. 화면을 밀어 밖에 있는 표본이 바뀌면 모양도 따라 바뀌었습니다.

**② 픽셀 열로 접기 · 칠하기가 화면 왼쪽 끝부터**

표본이 픽셀보다 촘촘하면 열마다 최소 · 최대로 접습니다 (차이 영역은 열 한가운데 값으로 칠함). 열을 **화면 왼쪽 끝부터**
잘라서, 1 픽셀이 안 되게만 밀어도 표본이 옆 열로 넘어가 최소 · 최대 · 칠하는 자리가 달라졌습니다 — 파형 · 차이 영역이 출렁임.

## 고침

| | 예전 | 1.75 |
|---|---|---|
| 화면 밖 | 위 · 아래 끝에 붙임 → 기울기 바뀜 · 끝선 가로줄 | 선분마다 끝과 만나는 자리를 계산해 그 안쪽만 (`LineClip` · `ClipLine`) — 밖은 안 그림 |
| 접기 · 칠하기 열 | 화면 왼쪽 끝부터 | **고정 시간 격자** (열 폭의 배수에서 시작) — 밀어도 같은 표본이 같은 열 (`Decimator.BuildGrid` · `SampleGrid` · `DifferenceSeries.BuildGrid`) |
| 이후 로그 | 자기 시간으로 따로 자름 | 같은 격자를 밀기 값만큼 옮겨 씀 — 두 선 · 차이 영역이 같은 열 |

확대 (열 폭이 바뀜) 하면 접는 열은 새로 잡히므로 바뀌는 것이 맞고, **같은 배율로 밀 때는 그대로**입니다.

## 확인
- 테스트 1129 통과 (새 것: 10 만 표본을 0.3 · 7.6 · 123.45 열 밀어도 같은 시각 열의 최소 · 최대 그대로 — 예전 방식은 달라짐을
  같이 확인, 위아래 자르기 넷), 실제 csc 7.3 오류 0, 검사 스크립트 통과
- **Windows 에서 못 봄**: 실제 그림 (밀 때 출렁임이 없는지 · 화면 밖으로 나가는 선) — 그림은 여기서 못 그림
