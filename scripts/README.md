# scripts/

**빌드에는 필요 없습니다.** `build.bat` 은 이 폴더를 쓰지 않고, 파이썬이
없어도 프로그램은 그대로 빌드되고 돌아갑니다.

여기 있는 것은 **컴파일 전에 미리 훑어보는 검사**입니다. 개발을 맡은 쪽
(Claude)이 도는 환경에 .NET 빌드 도구가 없어서, 컴파일러가 잡아 줄 만한
실수를 대신 잡으려고 만든 것입니다. 파이썬 3 만 있으면 됩니다.

```
python scripts\check_sources.py      전반 검사
python scripts\check_shadowing.py    이름 겹침(CS0136) 검사
```

둘 다 지적이 없으면 0 으로, 있으면 1 로 끝납니다.

## check_sources.py

| 보는 것 | 왜 |
|---|---|
| XAML 이 XML 로 읽히는지 | 태그가 안 닫히면 빌드가 실패합니다 |
| 밝은/어두운 테마의 열쇠가 같은지 | 한쪽에만 있으면 그 테마에서 화면이 깨집니다 |
| 쓰인 리소스 열쇠가 모두 정의돼 있는지 | 없는 열쇠는 실행 중에 터집니다 |
| XAML 의 이벤트 처리기가 코드 비하인드에 있는지 | 없으면 빌드가 실패합니다 |
| 괄호 균형이 이전 커밋 대비 달라졌는지 | 절대 개수는 문서 주석 때문에 원래 안 맞습니다 |
| `.csproj` 파일 목록과 실제 파일이 맞는지 | 빠진 파일은 조용히 안 컴파일됩니다 |

## check_shadowing.py

한 메서드 안에서 **바깥 수준과 안쪽 블록이 같은 이름을 선언**한 경우를
찾습니다. C# 이 `CS0136` 으로 막는 것입니다.

```csharp
void M() {
    for (...) { int jump = ...; }    // 안쪽
    ChannelDiff jump = ...;          // 바깥  ← CS0136
}
```

실제로 이걸 한 번 놓쳐서 빌드를 깨뜨린 적이 있어서 만들었습니다
([claude-log/13](../claude-log/13-shadowing-check.md)).

형제 블록끼리 같은 이름을 쓰는 것(`for` 두 개가 각각 `int i`)은 정상이라
잡지 않습니다. 헛경보를 내지 않는 대신, 안쪽-안쪽으로 겹친 경우는 놓칩니다.
