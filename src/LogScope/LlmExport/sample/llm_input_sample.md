## 요청

위 자료로 '종합 분석 결과' 를 한국어로 써 주세요.
1. 종합 판정: PASS / WARNING / FAIL 중 하나와 한 줄 이유.
2. 핵심 변화 3~7 개: 무엇이 · 어디서(IO · 단계 · 표) · 얼마나. 각 항목에 근거 섹션 Id 와 줄을 적을 것 (예: a1.ios PRES_MAIN).
3. 원인 후보: 분석 2 의 설정 변화가 분석 1 의 동작 변화로 이어진 짝을 '분석 사이 연결' 표로 근거를 들어. 짝이 없으면 없다고.
4. 분석 3 결과가 분석 1 · 2 와 맞는지 · 어긋나는지.
5. 확인할 것 목록: 사람이 직접 볼 IO · 단계 · 표.
지킬 것: 표에 없는 수치나 이름을 지어내지 말 것. '담지 못함' 이라고 적힌 분석은 판단에서 뺄 것. '… 외 N 줄' 이 있는 표는 일부만 본 것임을 감안할 것. 확실하지 않으면 확실하지 않다고 쓸 것.
